변경 내역

Chrome 웹 스토어에 출시된 GrokMediaDownloader의 모든 버전을 최신순으로 정리했습니다. 날짜는 해당 버전을 빌드한 날이며, 스토어 반영은 보통 며칠 뒤에 이루어집니다.

이슈 번호는 공개 GitHub 저장소에 등록된 신고를 가리킵니다. 2.6.0 릴리스 노트는 해당 버전이 Chrome 웹 스토어에 공개되면 이곳에 게시됩니다.

v2.5.6

2026-09-14 수정

태그는 빠짐없이, 파일명에는 프롬프트가 다시

두 가지 근본 원인을 수정했으며, 둘 다 Grok 쪽 변경에서 비롯된 문제입니다. 내용은 2.5.5와 같습니다. 2.5.5는 번들에 포함된(실행되지 않는) 서드파티 파일이 CDN을 참조한다는 이유로 Chrome 웹 스토어에 게시되지 않았고, 2.5.6에서 해당 파일을 제거했습니다.

  • 태그 다운로드가 파일 하나만 받아오던 문제(issue #13). Grok의 8월 태그 이전은 양방향 모두 불완전합니다. 새 컬렉션 API에는 과거 항목이 거의 없고 과거 기록은 기존 폴더 API에 남아 있으며, 각각 상대에게 없는 태그를 가지고 있습니다. 이제 태그 목록과 태그 내용은 두 API의 합집합이 되며, 2개만 반환되던 태그가 이제 233개를 반환합니다.
  • 파일명, 폴더명, metadata.json에 프롬프트가 없던 문제. 9월부터 Grok은 미디어 목록과 함께 프롬프트를 보내지 않습니다. 이제 해당 항목을 생성한 대화에서 프롬프트를 되찾아오며(동영상은 자체 애니메이션 프롬프트를 사용하거나 원본 이미지의 프롬프트를 가져옵니다), 재시도, 서킷 브레이커, 영구 캐시를 갖추었습니다. 전체 라이브러리 목록 재생성은 두 번째 실행에서 129초에서 10초로 줄었습니다.
  • 프롬프트는 파일명이나 메타데이터 설정이 실제로 필요로 할 때만 가져옵니다. 해당 설정을 변경하면 팝업이 목록을 다시 생성하라고 안내합니다.
  • metadata.json에 userId가 기록되고, 동영상 파일명이 짧은 ID 접미사까지 포함해 목록과 일치하며, 일부만 실패한 태그 소스는 성공이 아닌 부분 완료로 표시됩니다.

실제 브라우저에서 처음부터 끝까지 검증했습니다. 61개 파일의 태그 다운로드와 206개 파일의 7일간 전체 라이브러리 다운로드를 Grok API와 파일 단위로 대조했습니다.

v2.5.4

2026-09-03 수정

오래된 태그와 태그 내용 전체

태그 목록에서 오래된 태그가 누락되거나, 태그 내용이 첫 페이지 이후로 불러와지지 않을 수 있었습니다.

  • 두 요청 모두 이제 Grok 웹 앱과 동일한 파라미터를 사용하며 모든 페이지를 읽습니다.
  • 도중에 한 페이지가 실패해도 전체 배치를 버리지 않고 이미 가져온 항목은 유지합니다.

v2.5.3

2026-08-31 수정

태그 페이지네이션과 스캔 진단

태그가 많은 계정을 위한 2.5.2 후속 수정입니다.

  • 태그 목록과 태그 내용의 페이지네이션을 수정했습니다.
  • "마지막 동영상만 업그레이드되었다"는 신고를 추적하기 위해 시스템 로그에 전체 스캔 진단 정보를 기록합니다.

v2.5.2

2026-08-22 수정

새로 만든 태그가 다시 표시됨

Grok이 태그를 에셋 모델 기반의 컬렉션으로 재구축하면서 기존 폴더 API가 더 이상 갱신되지 않아, 변경 이후 만든 태그가 확장 프로그램에 보이지 않았습니다.

  • 태그 목록과 태그 다운로드를 Grok의 현재 API로 전환했으며, 아직 이전되지 않은 계정은 자동으로 기존 API로 대체합니다.
  • 태그 다운로드에도 전체 라이브러리 소스처럼 프롬프트 기반 파일명이 적용됩니다.
  • 진단을 위해 모든 HD 업그레이드 응답을 시스템 로그에 기록합니다.

v2.5.1

2026-08 수정

기본 다운로드 소스가 고장 나서 변경했습니다

실제 계정에서 측정한 결과 라이브러리의 최신 항목 30개 중 11개가 즐겨찾기 목록에서 누락되었고, Grok 자체의 Saved 페이지도 더 이상 해당 엔드포인트를 호출하지 않습니다.

  • 기본 소스가 이제 전체 라이브러리("모든 생성 미디어")입니다. 이미 소스를 선택한 사용자는 기존 선택이 유지됩니다.
  • 다운로드 소스 선택기는 모두에게 무료입니다. 자신의 미디어를 볼 수 없는 소스에 묶여 있어서는 안 되기 때문입니다.
  • 무료 버전에서도 최근 7일간의 전체 라이브러리를 스캔할 수 있습니다.
  • 기존 소스가 선택되어 있을 때, 아무것도 찾지 못했을 때, HD 업그레이드할 항목이 없다고 나올 때 명확한 안내를 표시합니다.

v2.5.0

2026-07-26 기능 릴리스

Grok의 새 미디어 백엔드 대응: 전체 라이브러리 다운로드와 1080p

Grok이 2026년 7월 대화 + 에셋 기반 백엔드로 전환하면서 이전 버전은 새 미디어를 인식할 수 없게 되었습니다. 이번 릴리스(공개되지 않았던 2.4.0의 작업도 포함)는 새 API를 기반으로 감지 기능을 재구축합니다.

  • 세 가지 다운로드 소스: 즐겨찾기, 태그, 그리고 새로운 대화별 전체 라이브러리. 소스마다 별도의 다운로드 기록, 조기 중단 날짜 필터, 대화별 폴더를 제공합니다.
  • 1080p를 독립된 품질 계층으로: 다운로드는 가능한 최고 화질을 받고, 통계는 1080p를 별도로 표시하며, 업그레이드는 한 단계씩 진행됩니다(SD → HD, 720p/HD → 1080p). 1080p 업그레이드는 선택 사항이며 계정에 권한이 없으면 즉시 중단됩니다.
  • 전체 라이브러리 HD 업그레이드: 즐겨찾기뿐 아니라 전체 라이브러리를 대상으로 하며, 확인 전에 화질별 내역을 보여 주고 스캔 중에는 중지 버튼을 제공합니다.
  • 파일 이름: 이미지 파일명은 실제 생성 프롬프트를, 동영상은 원본 이미지의 프롬프트를 사용하고, 폴더는 yyyymmdd_prompt_shortid 형식을 쓰며, "Grok 네이티브" 모드는 문서화된 형식과 일치합니다.
  • 스캔 결과가 실행할 때마다 일정하며, 15,000개 이상의 항목이 있는 라이브러리에서도 메모리 사용량이 늘지 않습니다.
