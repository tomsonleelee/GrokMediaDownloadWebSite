下載 Grok Imagine 影片並保留提示詞

把提示詞寫進檔名、套用自己的命名規則，或在每個下載檔案旁另存一份含完整提示詞的 .json。

快速解答

安裝 GrokMediaDownloader 並開啟 grok.com/library。在彈出視窗打開 ⚙️ 設定，於 📝 檔名格式 選擇 使用提示詞，或選 自訂模板 並放入 {prompt}。再勾選 📋 儲存 Metadata，每個檔案旁就會多一份含完整提示詞的 .json。接著按 1. 生成下載列表 和 2. 開始下載。檔名與 metadata 選項全部免費，下載圖片即可使用；下載影片需要 PRO。

保留提示詞的三種方式

三種方式可以同時使用。它們都是擴充功能彈出視窗裡的設定，不會更動 Grok 上的任何內容。

提示詞寫進檔名

「使用提示詞」格式會把檔案命名成 img_20261128143015_a_red_fox_in_fresh_snow_1a2b3c4d.jpg 這樣，之後在電腦裡就能直接用提示詞搜尋。

自己的命名規則

「自訂模板」可以把 {date}、{prompt}、{shortid} 等變數組合成符合你整理習慣的檔名。

完整提示詞存成 .json

「儲存 Metadata」會在每個下載檔案旁另存一份小小的 .json，記錄完整提示詞、建立時間和 ID，影片還會記錄實際下載的畫質。

保存提示詞：免費版與 PRO

檔名與 metadata 相關功能全部免費。PRO 增加的是影片下載和完整媒體庫。

操作步驟

  1. 1

    步驟 1: 安裝擴充功能並開啟 Grok

    從 Chrome 線上應用程式商店 加入 GrokMediaDownloader，並把圖示釘選到工具列。請在同一個 Chrome 設定檔中登入 Grok。

    開啟 Grok 的 Library（媒體庫）頁面 grok.com/library。2.6.3 版起，任何 grok.com 頁面都能使用；如果目前分頁不是 grok.com，彈出視窗會請你先開啟 Grok。

  2. 2

    步驟 2: 選擇檔名格式

    點擊擴充功能圖示開啟彈出視窗，展開 ⚙️ 設定。如果你是 PRO 用戶並使用精簡模式，請先點彈出視窗上方的 全 按鈕，因為精簡模式會隱藏設定區塊。

    在 📝 檔名格式 選擇 使用提示詞，檔名就會由日期、時間和提示詞組成。想自己決定順序，就選 自訂模板，再到 圖片： 和 影片： 欄位輸入規則。Grok 原生 則保留以 ID 為主、不含提示詞的短檔名。

    設定一變更就會自動儲存。

  3. 3

    步驟 3: 開啟「儲存 Metadata」保存完整提示詞

    在同一個區塊勾選 📋 儲存 Metadata（「同時儲存 .json 檔案，包含圖片/影片資訊（提示詞、解析度等）」）。之後每張圖片、每支影片旁邊都會有一份同名的 .json 檔。

    檔名會把過長的提示詞截短，完整的提示詞就保存在 .json 裡。這個選項可以搭配任何檔名格式，包括 Grok 原生。

  4. 4

    步驟 4: 選擇來源並生成列表

    在 📥 下載來源與篩選 選擇 📦 所有生成媒體（依對話）（預設值，也就是整個媒體庫）、🌟 收藏 或 🏷️ 標籤。在 🎬 媒體類型 保持勾選 🖼️ 圖片；🎬 視頻 (Pro) 需要 PRO 才能勾選。

    按 1. 生成下載列表。如果你的設定會用到提示詞，按鈕會顯示 📝 擷取提示詞 和進度數字，代表擴充功能正從產生每個項目的對話中找回提示詞。沒有自己提示詞的影片，會沿用來源圖片的提示詞。找到過的提示詞會存在本機快取，之後再生成就快得多。

    掃描結束後，彈出視窗會跳出 📊 下載摘要 對話框，列出要下載的圖片與影片數量、各畫質的影片數，並詢問「確定開始下載？」。按「確定」會立即開始下載；按「取消」則關閉對話框，2. 開始下載 仍可點擊，方便你先檢查設定，下方截圖就是這個狀態。

  5. 5

    步驟 5: 開始下載

    如果剛才在摘要中按了「取消」，現在按 2. 開始下載。進度條會顯示目前進度與預估剩餘時間。⏹ 中斷下載 可以暫停，▶ 繼續下載 會從中斷處接著下載。

    每個下載來源都有自己的下載紀錄，所以再跑一次時會略過已經存過的檔案。為了不超過 Grok 的頻率限制，擴充功能每下載 250 支影片會暫停一次（預設 3 分鐘，可在 ⚙️ 設定 調整），之後自動繼續。

  6. 6

    步驟 6: 找到檔案和提示詞

    檔案會存到 Chrome 下載資料夾裡的 grok_downloads/。收藏存到 images/ 和 videos/，標籤存到 tags/ 底下的各標籤資料夾，整個媒體庫則存到 conversations/，每個對話一個資料夾，以日期、標題或提示詞再加上短 ID 命名。這些路徑可以在 ⚙️ 設定 中修改。

    開啟儲存 Metadata 後，每個媒體檔旁邊都會有它的 .json 檔。

「使用提示詞」的檔名長這樣

實際格式依下載來源而定。以下範例的提示詞是「a red fox in fresh snow」。

來源圖片影片
📦 所有生成媒體img_20261128143015_a_red_fox_in_fresh_snow_1a2b3c4d.jpgvid_20261128143015_a_red_fox_in_fresh_snow_9e8d7c6b.mp4
🌟 收藏、🏷️ 標籤img_20261128143015_a_red_fox_in_fresh_snow.jpghd_20261128143015_a_red_fox_in_fresh_snow.mp4

14 位數字是建立日期與時間（YYYYMMDDHHmmss），以你電腦的時區為準。

整個媒體庫的檔名最後會加上項目 ID 的末 8 碼，所以就算兩個項目提示詞相同、又在同一秒產生，也不會撞名。

收藏和標籤來源的影片檔名以 hd_ 或 sd_ 開頭，代表實際下載的畫質。

自訂模板可用的變數

選擇「自訂模板」後，分別替圖片和影片各輸入一組規則。擴充功能會替換每個變數，並自動加上副檔名。

變數代表範例
{date}建立日期2026-11-28
{time}建立時間（時、分、秒）143015
{datetime}日期加時間2026-11-28_143015
{id}項目在 Grok 的完整 ID完整 ID
{shortid}ID 的末 8 碼1a2b3c4d
{prompt}整理成適合檔名、最多 80 個字元的提示詞a_red_fox_in_fresh_snow
{quality}收藏與標籤來源的影片為 hd 或 sd；圖片和整個媒體庫則為空白hd

範例：圖片規則填 {date}_{prompt}_{shortid}，會得到 2026-11-28_a_red_fox_in_fresh_snow_1a2b3c4d.jpg。

無法辨識的變數會被移除。如果規則裡沒有 {id}、{shortid} 或 {datetime}，彈出視窗會警告「⚠ 無唯一識別變數 — 檔案可能互相覆蓋」。加上其中一個，每個檔案就會有自己的名稱。

沒有提示詞的項目，{prompt} 會改用部分 ID。模板欄位留空時，檔案會以 ID 命名。

.json 檔裡有什麼

開啟 📋 儲存 Metadata 後，每個下載的檔案都會有一份同名的 .json。提示詞會照原樣保存，連不能出現在檔名裡的字元也都在。欄位包括：

  • prompt 和 originalPrompt：提示詞內容
  • createTime：項目建立時間；downloadedAt：你下載的時間
  • id、type、url 和 filename：是哪個項目、從哪裡下載
  • userId：你的 Grok 帳號 ID
  • 影片另外還有 hdUrl、detailUrl 和 downloadedQuality（hd 或 sd）

以下是一支影片的精簡範例：

{
  "id": "…",
  "type": "video",
  "url": "…",
  "filename": "vid_20261128143015_a_red_fox_in_fresh_snow_9e8d7c6b.mp4",
  "createTime": "2026-11-28T14:30:15.000Z",
  "prompt": "a red fox in fresh snow, slow camera pan",
  "originalPrompt": "a red fox in fresh snow, slow camera pan",
  "downloadedQuality": "hd",
  "downloadedAt": "2026-11-28T15:02:41.000Z"
}

檔案裡含有你的 Grok 使用者 ID，公開分享資料夾前，可以考慮先把 .json 檔移除。

專案資料夾與 metadata.json（收藏來源）

使用 🌟 收藏 來源時，📂 下載模式 可以選 依專案分組。每個專案資料夾會放來源圖片、由它生成的影片，以及一份 metadata.json。資料夾以日期、提示詞和短 ID 命名，例如 20261128_a_red_fox_in_fresh_snow_1a2b3c4d。

metadata.json 會列出資料夾的提示詞與建立時間、來源圖片，以及每支生成影片各自的提示詞和下載連結，另外還有圖片與影片數量統計。不論是否開啟儲存 Metadata，每個專案資料夾都會寫入這份檔案。之前用標準模式下載過的檔案會被略過；如果想要完整的專案資料夾，彈出視窗會建議先清除下載紀錄。

專案資料夾只提供給收藏來源，而且以影片為主，所以搭配 PRO 最實用。Grok 在 2026 年 7 月更改媒體後端後，許多帳號新生成的媒體不再出現在收藏裡。這些項目請改用 📦 所有生成媒體：每個對話資料夾本來就會把圖片和由它生成的影片放在一起。

檔名長度與字元規則

提示詞是寫給 AI 看的，不是為檔案系統設計的，所以擴充功能拿來當檔名前會先整理：

  • 移除檔名中不安全的字元（ \ / : * ? " < > | ），以及換行和 Tab。
  • 空格換成底線，連續的底線合併成一個。
  • 過長的提示詞會被截斷：整個媒體庫的「使用提示詞」檔名最多 100 個字元，收藏和標籤最多 120 個，{prompt} 變數最多 80 個，專案資料夾名稱最多 90 個。
  • 以 @ 加上 ID 寫成的圖片引用，以及提示詞結尾的選項參數（例如 --mode=…）不會放進檔名；.json 則保留原始提示詞。
  • 中文、日文、韓文等非拉丁文字會原樣保留。
  • 沒有提示詞的項目（例如你自己上傳的圖片）會以 ID 命名。

這些規則都不會影響 .json 檔，所以只要開啟儲存 Metadata，完整提示詞就一定會留著。

彈出視窗要求重新生成列表時

找回提示詞需要時間，所以擴充功能只在設定真的用得到時才會去找：使用提示詞檔名、含 {prompt} 的自訂模板，或儲存 Metadata。

如果你在 Grok 原生檔名、未開啟 metadata 的狀態下生成了列表，之後才開啟上述任一項，彈出視窗會顯示 ⚠️ 提示詞檔名／metadata 需要提示詞，請重新生成列表。開始下載前請再按一次 1. 生成下載列表，否則新下載的檔案不會帶有提示詞。

疑難排解

保存提示詞時最常遇到的問題，以及各自的解法。

檔名是 ID，而不是提示詞
常見原因有三個。該項目本來就沒有提示詞，例如你上傳的圖片。或是列表在你修改檔名設定之前就已生成，請重新生成。也可能是列表由舊版擴充功能產生：請先更新擴充功能，再重新生成列表。Chrome 會自動更新擴充功能；想立即更新，可以開啟 chrome://extensions，打開「開發人員模式」後按「更新」。
彈出視窗顯示「提示詞檔名／metadata 需要提示詞」
你的設定現在會用到提示詞，但目前的列表生成時並沒有抓取提示詞。請再按一次 1. 生成下載列表，然後按 2. 開始下載。
「視頻」核取方塊是灰色的，旁邊還有鎖頭
下載影片是 PRO 功能。免費版可以下載圖片，所有檔名與 metadata 選項也都能用。PRO 為一次性購買 $4.99（價格）。購買後，把 GMD-… 授權碼貼到彈出視窗的 🔑 授權。
生成列表一直停在「擷取提示詞」
第一次執行時要逐一找回列表中每個對話的提示詞，媒體庫很大時會花一些時間。如果 Grok 限制這些查詢的頻率，擴充功能會等待後重試。之後再生成會使用本機的提示詞快取，速度快很多。PRO 用戶也可以用日期篩選縮小大型掃描的範圍。
兩個檔案變成同一個檔名
你的自訂模板缺少唯一識別變數。請加上 {shortid}、{id} 或 {datetime}。整個媒體庫的「使用提示詞」檔名結尾本來就有短 ID。
改了格式，但以前下載的檔案還是舊檔名
擴充功能不會重新命名已經在你電腦裡的檔案，下載紀錄也會略過它們。想用新檔名重新下載，請打開 🧹 清除操作，清除該來源的紀錄：整個媒體庫用「清除對話歷史」，收藏用「重置下載歷史」，標籤用「清除標籤歷史」。接著重新生成列表並開始下載。清除紀錄不會刪除 Grok 上或電腦裡的任何東西。

常見問題

可以自動下載 Grok Imagine 影片並保留提示詞嗎？

可以。在 ⚙️ 設定 選擇「使用提示詞」或含 {prompt} 的自訂模板；如果也想把完整提示詞存成 .json，再開啟 📋 儲存 Metadata。之後下載的每個檔案都會帶著提示詞。下載影片需要 PRO，圖片在免費版就能下載。

保存提示詞要付費嗎？

不用。檔名格式、自訂模板和 .json 檔對所有人免費。PRO 為一次性購買 $4.99，增加影片下載、最近 7 天以外的媒體庫，以及日期篩選。詳情請見價格頁。

檔名被截短了，完整提示詞在哪裡？

在媒體檔旁邊的 .json 檔裡，開啟 📋 儲存 Metadata 時才會產生。檔名會截短以便使用，.json 則保存原本記錄的提示詞。

中文、日文等其他語言的提示詞也能用嗎？

可以。擴充功能只會移除檔名中不安全的字元，中文、日文、韓文和帶重音的字母都會照原樣留在檔名裡。

由圖片生成的影片會用哪個提示詞？

影片有自己的動態提示詞時就用它自己的。沒有提示詞的影片會沿用來源圖片的提示詞，檔名一樣有意義。

我的提示詞會被上傳到其他地方嗎？

不會。擴充功能在你的瀏覽器裡執行，檔案直接從 Grok 存到你的電腦。它唯一連線的外部服務是 Kario Studio 的授權伺服器，用來驗證 PRO 授權碼。
