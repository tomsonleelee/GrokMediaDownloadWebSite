Grok のお気に入りが表示されない？ライブラリをバックアップする方法

Grok のお気に入りが空になっている、古い項目までしか表示されない、今週作ったものが出てこない。そんなことはありませんか？原因はたいていブラウザではありません。Grok は2026年7月にメディアの保存方法を変更し、多くのアカウントでは古いお気に入りリストに新しい作品が入らなくなりました。このガイドでは、何が変わったのか、何が今も使えるのか、そして Grok のライブラリの完全なコピーを自分のディスクに残す方法を説明します。

結論

Grok の2026年7月のメディアバックエンド変更以降、多くのアカウントで、新しく生成した画像や動画が古いお気に入りリストに追加されなくなりました。このリストを読み取るツールでは、最近の作品が抜け落ちます。メディアそのものは Grok のライブラリに残っています。

バックアップするには、grok.com/library を開いて Grok Media Downloader のアイコンをクリックし、ダウンロード元として📦 すべての生成メディア（会話別）を選んでから、1. リスト生成、2. ダウンロード開始の順にクリックします。無料版では直近7日間の画像を保存できます。PRO では動画、ライブラリ全体、日付フィルターが加わります。

2026年7月の変更点

2026年7月、Grok はメディアを「会話」と「アセット」を軸にした新しいバックエンドへ移行しました。生成した画像や動画は、いまではすべてどれかの会話に属し、アセットとしてライブラリに保存されます。この変更以降、多くのアカウントで、古いお気に入りリスト（Grok の画面では Saved と表示）に新しく生成したメディアが追加されなくなりました。

この影響は見落としがちです。リストには以前の項目が残っていることがあるので、壊れているようには見えません。最近生成したものが入っていないだけです。このリストに頼るツールにも同じ抜けが生じます。古いバージョンのブラウザ拡張機能や、Grok Media Downloader の🌟 お気に入りソースも例外ではありません。

Grok Media Downloader はバージョン2.5.0で新しいバックエンドに対応しました。バージョン2.5.1以降は、お気に入りリストではなくライブラリ全体を読み取る📦 すべての生成メディア（会話別）ソースが既定になり、誰でも無料で使えます。現在のポップアップでは、お気に入りソースの下に次の注意が表示されます：「⚠️ Grok の2026年7月の変更以降、新しく生成されたメディアはお気に入りに追加されません。最新の項目がここに表示されない場合があります。」

Grok のページ自体が表示されない場合

grok.com が真っ白になる、エラーメッセージが出る、読み込み中のまま進まないといった症状は、Grok 側か接続環境の問題で、どの拡張機能でも直せません。Grok のヘルプを確認するか、時間をおいてもう一度お試しください。以下の手順は、grok.com が正常に表示される状態でメディアを手元に保存するためのものです。

今も使えるもの

  • ライブラリ。変更後に生成したメディアも Grok のライブラリに保存されています。「📦 すべての生成メディア」ソースはこのライブラリを直接読み取るので、お気に入りのスキャンでは見つからない最近の作品も、生成元の会話ごとにまとめて見つけられます。
  • 以前のお気に入り。「🌟 お気に入り」ソースは、古いリストに入っているものを今もダウンロードできます。厳選したそのセットだけが欲しいときに使ってください。
  • タグ。Grok のタグで作品を整理しているなら、「🏷️ タグ」ソースで1つのタグの中身をすべてダウンロードできます。
  • ダウンロード履歴。保存済みの記録はソースごとに別々に残るので、同じバックアップをもう一度実行しても新しいファイルだけが取得されます。

つまり、お気に入りリストは作品の一部しか映さなくなった一方で、ライブラリは今も完全です。ライブラリを読み取るバックアップなら、このリストにはまったく左右されません。

2026年11月：Imagine が Grok の Library に統合

2026年11月12～13日には、2つ目の変更がありました。Grok は Imagine をメインの Grok アプリに統合し、サイドバーには Library が表示されるようになりました。一部のアカウントでは Imagine タブと /imagine のページがなくなり、これらのアドレスは Library かトップページへリダイレクトされます。これまで Imagine タブからお気に入りを開いていた場合は、サイドバーの Library を探すか、grok.com/library を直接開いてください。

2.6.3より前の拡張機能は /imagine のページでしかボタンを有効にしなかったため、この変更後は1. リスト生成と2. ダウンロード開始がグレーアウトしたままになることがありました。バージョン2.6.3はどの grok.com のページでも動作し、使う場所としては grok.com/library をおすすめします。ボタンがグレーアウトしている場合は、まずGrok のアップデート後にダウンロードボタンが消えた・押せないときの対処法に沿って対処し、そのあとこのページに戻ってきてください。

Grok のライブラリをまるごとバックアップする手順

以下の手順では「📦 すべての生成メディア（会話別）」ソースを使います。このソースはお気に入りリストではなくライブラリを読み取り、会話ごとに1つのフォルダへファイルを振り分け、ダウンロード済みのものはスキップします。ライブラリが大きいと初回の実行に時間がかかることがあるので、タブを開いたままにしておけるときに始めてください。

  1. 1

    Grok Media Downloader をインストールまたは更新する

    Chromeウェブストアから Grok Media Downloader を追加し、アイコンが常に見えるようツールバーに固定します。すでに入っている場合は、バージョンが2.6.3以降か確認してください。chrome://extensions を開き、拡張機能のカードに表示されたバージョン番号を見ます。

  2. 2

    grok.com を開いてサインインする

    grok.com/library を開き、バックアップしたいアカウントでサインインしていることを確認します。バージョン2.6.3以降はどの grok.com のページでも動作し、grok.com/imagine/saved が残っているアカウントではそのページでも使えます。拡張機能のアイコンをクリックするときは、このタブをアクティブにしておいてください。

  3. 3

    ダウンロード元で「📦 すべての生成メディア」を選ぶ

    拡張機能のアイコンをクリックしてポップアップを開きます。📥 ダウンロード元とフィルターセクションの🎯 ダウンロード元で、📦 すべての生成メディア（会話別）を選びます。現行バージョンでは既定で選ばれていますが、以前にソースを切り替えたことがあれば確認してください。無料版では、その下に次の注記が表示されます：「ℹ️ 無料版は直近7日間のみスキャンします。Pro にアップグレードすると全ライブラリと日付フィルターが使えます。」

  4. 4

    メディアの種類と、PRO なら日付範囲を選ぶ

    🎬 メディアタイプでは🖼️ 画像にチェックを入れたままにします。無料版では🎬 動画 (Pro)はロックされています。PRO なら、実行範囲を日付範囲や直近数時間に絞ることも、フィルターをすべてダウンロードのままにしてすべてをアーカイブすることもできます。無料版の実行は常に直近7日間が対象です。

  5. 5

    「1. リスト生成」をクリックする

    拡張機能がライブラリを新しい順にスキャンし、見つかった項目を数えます。スキャン中は、これまでに見つかった件数がポップアップに表示されます。完了すると📊 ダウンロード概要のダイアログが開き、まだダウンロードが必要な画像と動画の件数（動画は 1080p・HD・720p・SD 別）を示して「ダウンロードを開始しますか？」と確認します。「OK」をクリックするとすぐに始まります。先にリストを確認したい場合は「キャンセル」をクリックしてください。件数はポップアップに残り、2. ダウンロード開始も有効なままです。

    スキャンが途中で止まった場合は「スキャン中断 — 一部のリストを保存しました」と表示されます。数分待ってから、もう一度1. リスト生成をクリックしてください。

  6. 6

    ダウンロードを開始する

    概要ダイアログで「OK」を選んだ場合は、すでにダウンロードが始まっています。そうでなければ2. ダウンロード開始をクリックします。ファイルは1件ずつ順番にダウンロードされます。進捗バーと残り時間の目安で進み具合がわかり、⏹ ダウンロード中止で止められます。実行が終わるまで grok.com のタブは開いたままにしてください。後で続きを行うには、もう一度2. ダウンロード開始をクリックします。保存済みのファイルはスキップされます。動画が250本を超える実行には、あらかじめ決められた一時停止が入ります。250本ごとに拡張機能が待機し（既定では3分）、その後自動で再開します。このことは開始前にダウンロード概要で知らされます。待機時間は⚙️ 設定の⏱️ レート制限クールダウンで1～60分の範囲で変更できます。

  7. 7

    保存されたファイルを確認する

    ファイルは Chrome のダウンロードフォルダに保存されます。ライブラリ全体ソースでは grok_downloads/conversations の下に会話ごとのフォルダが作られるので、画像とそこから作った動画が同じ場所にまとまります。フォルダ名は⚙️ 設定で変更できます。

  8. 8

    ときどきバックアップを繰り返す

    バックアップを最新の状態にしたいときは、もう一度1. リスト生成と2. ダウンロード開始をクリックします。ダウンロードされるのは新しいファイルだけです。無料版なら、週に1回実行すれば画像の7日間の範囲に追いつけます。

トラブルシューティング

Grok の2026年の変更後に起きる問題の多くは、選んでいるソース、無料版の7日間の範囲、アクティブなタブのどれかが原因です。まずはこちらを確認してください。

「1. リスト生成」で何も見つからない

3つの点を確認してください。1つ目はダウンロード元です。「🌟 お気に入り」になっていれば「📦 すべての生成メディア（会話別）」に切り替えます。2つ目は期間です。無料版は直近7日間しか見ないので、その間に何も生成していなければリストは空になります。3つ目はダウンロード履歴です。リストにはまだダウンロードが必要なファイルしか数えられないため、すべて保存し終えた後は何も残っていないことがあります。

最新の画像がリストに入っていない

リストは「1. リスト生成」をクリックした時点のスナップショットです。ソースが「🌟 お気に入り」ではなく「📦 すべての生成メディア」になっていることを確認し、前回のスキャン以降に作ったものも含まれるよう、リストを生成し直してください。

「1. リスト生成」と「2. ダウンロード開始」がグレーアウトしている

アクティブなタブが grok.com のページではないか、拡張機能が2.6.3より古く grok.com/library で動作しないかのどちらかです。Grok のアップデート後にダウンロードボタンが消えた・押せないときの対処法をご覧ください。

動画がダウンロードされない

無料版は画像のみをダウンロードするため、「🎬 動画 (Pro)」はロックされています。PRO の場合はチェックを入れ、開始する前にもう一度「1. リスト生成」をクリックしてください。

長時間の実行中にダウンロードが失敗し始める

非常に長い実行では、Grok がダウンロードを拒否し始めることがあります。たとえば数千本の動画の後に HTTP 403 エラーが出るケースです。grok.com のタブを再読み込みし、ポップアップを開いて、もう一度「2. ダウンロード開始」をクリックしてください。保存済みのファイルはスキップされます。

ポップアップに「生成に失敗しました」と表示される

grok.com にサインインしていることを確認し、タブを再読み込みしてからもう一度お試しください。

ファイルを削除したのに、拡張機能がすべてダウンロード済みと表示する

ダウンロード履歴はソースごとに別々に記録されています。ライブラリ全体ソースの場合は、「🧹 クリア操作」を開いて「会話履歴を消去」をクリックします。リセットされるのは拡張機能の記録だけで、Grok 上やディスク上のものは何も削除されません。

よくある質問

お気に入りにない Grok のメディアは消えてしまったのですか？

たいていは消えていません。2026年7月以降、多くのアカウントで新しく生成したメディアは古いお気に入りリストに追加されなくなりましたが、Grok のライブラリには保存されています。「📦 すべての生成メディア」ソースはライブラリを読み取るため、お気に入りのスキャンでは見つからない最近の作品も見つけられます。Grok の Library にも見当たらない場合は、Grok のヘルプを確認してください。

Grok のライブラリは無料でバックアップできますか？

はい、制限付きでできます。無料版では「📦 すべての生成メディア」ソースで直近7日間の画像をダウンロードできます。PRO（$4.99 の買い切り）では、動画、期間の制限がないライブラリ全体、日付フィルターが加わります。料金ページをご覧ください。

ダウンロードしたファイルはどこに保存されますか？

Chrome のダウンロードフォルダです。ライブラリ全体ソースは grok_downloads/conversations を使い、会話ごとに1つのフォルダを作ります。お気に入りソースは grok_downloads/images と grok_downloads/videos、タグソースは grok_downloads/tags を使います。これらのパスは「⚙️ 設定」で変更できます。

バックアップをもう一度実行すると、重複してダウンロードされますか？

同じソース内では重複しません。ソースごとにダウンロード履歴が残り、保存済みのファイルはスキップされるので、次回の実行では新しいメディアだけがダウンロードされます。ただし、履歴はソース間で別々です。「🌟 お気に入り」で保存したファイルが、「📦 すべての生成メディア」でもう一度ダウンロードされることはあります。

お気に入りソースはまだ使うべきですか？

古いお気に入りリストに入っているセットだけが欲しいなら使ってください。2026年7月以降に生成したもの、または完全なバックアップには「📦 すべての生成メディア（会話別）」を使ってください。

拡張機能がメディアをどこかにアップロードすることはありますか？

ありません。処理はすべてブラウザ内で行われ、ファイルは Grok から直接ディスクに保存されます。外部との通信は PRO ライセンスの確認だけで、その際は Kario Studio のライセンスサーバーに接続します。
