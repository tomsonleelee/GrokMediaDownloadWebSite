스트림 캡처

실시간 Grok 이미지 자동 캡처

grok.com 탭에서 켜면 스트림 캡처가 DOM 관찰자로 그 탭에서 Grok이 생성한 이미지를 실시간으로 모읍니다. 탭을 새로고침하거나 닫기 전에 클릭 한 번으로 모두 다운로드하세요.

Chrome에 추가

스트림 캡처 실제 동작 보기

활성화 → Imagine에서 생성 → 이미지 자동 캡처 → 캡처된 항목 다운로드

* 스트림 캡처 실시간 캡처 워크플로우를 보여주는 동영상입니다

핵심 기능

스트림 캡처는 원활한 실시간 이미지 수집 워크플로우를 제공합니다

실시간 DOM 옵저버

MutationObserver를 사용하여 Grok이 이미지를 생성할 때 새 이미지를 감시합니다. 수동 새로고침 없이 즉시 감지됩니다.

자동 캡처 목록

약 120KB 이상인 생성 이미지가 캡처 목록에 추가되고, 썸네일과 아이콘은 건너뜁니다. 팝업에 개수가 표시되며 한 세션에 최대 1,000장입니다.

원클릭 일괄 다운로드

브라우징이 끝나면 캡처된 모든 이미지를 한 번에 다운로드하세요. 더 이상 하나씩 저장할 필요가 없습니다.

세션 내 중복 없음

이번 세션의 캡처 목록에 이미 있는 이미지는 다시 추가되지 않습니다.

스트림 캡처 작동 방식

생성한 이미지를 캡처하는 4단계

1

켜기

grok.com 탭에서 팝업을 열고 '🌊 스트림 캡처' 섹션의 '활성화'를 켭니다.

2

Imagine에서 생성

평소처럼 Grok Imagine에서 이미지를 생성하세요. Grok이 페이지에 넣는 새 이미지가 자동으로 캡처됩니다.

3

개수 확인

팝업에 캡처한 이미지 수가 표시됩니다. 처음부터 다시 하려면 '캡처 삭제'로 목록을 비우세요.

4

일괄 다운로드

'캡처된 항목 다운로드'를 누르면 캡처한 이미지를 모두 grok_downloads/stream에 한 번에 저장합니다. 탭을 새로고침하거나 닫기 전에 다운로드하세요.

기술적 특징

MutationObserver API

브라우저의 네이티브 MutationObserver를 사용하여 성능 영향 없이 효율적으로 DOM 변경 사항을 감지합니다.

grok.com 탭 안에서 실행

캡처는 기능을 켠 grok.com 탭 안에서 이루어지고, 캡처한 이미지는 그 탭의 메모리에 보관됩니다. 새로고침하거나 탭을 닫으면 사라지므로 먼저 다운로드하세요.

세션당 최대 1,000장

한 세션에 최대 1,000장까지 보관합니다. 한도에 도달하면 캡처가 멈추고, 다운로드한 뒤 목록을 비우라고 안내합니다.

프라이버시 우선

모든 이미지 감지 및 다운로드는 로컬에서 이루어집니다. 어떠한 데이터도 외부 서버로 전송되지 않습니다.

스트림 캡처 vs 수동 다운로드

Grok 생성 이미지를 수집할 때 자동화된 스트림 캡처가 수작업 시간을 얼마나 절약하는지 확인하세요.

기능 수동 다운로드 스트림 캡처
감지 방식
페이지를 수동으로 확인해야 함 MutationObserver로 새 이미지 자동 감지
속도

새 콘텐츠를 놓치기 쉬움 표시되는 생성 이미지(약 120KB 이상)를 캡처
노력
높음 — 지속적인 모니터링 필요 낮음 — 평소처럼 생성하면 그 탭에서 캡처
최대 수량
해당 없음 세션당 최대 1,000장

스트림 캡처로 하나씩 클릭해 저장하는 수고를 덜 수 있습니다. 평소처럼 Grok Imagine에서 만들면 확장 프로그램이 그 탭에서 생성된 이미지를 모읍니다.

자주 묻는 질문

스트림 캡처에 관한 모든 질문에 답변드립니다

스트림 캡처는 무엇을 캡처하고 어디서 작동하나요?

기능을 켠 grok.com 탭을 지켜보며, Imagine에서 만드는 동안 Grok이 페이지로 보내는 생성 이미지를 모읍니다. 썸네일이나 아이콘 같은 작은 이미지(약 120KB 미만)는 무시하며, 이미지만 캡처하고 동영상은 캡처하지 않습니다.

최대 몇 장까지 캡처할 수 있나요?

한 세션에 최대 1,000장입니다. 1,000장에 도달하면 멈추고, 계속하기 전에 캡처한 이미지를 다운로드하고 지우라고 안내합니다.

캡처한 이미지는 어떻게 저장하나요?

팝업에서 '캡처된 항목 다운로드'를 누르세요. 파일은 다운로드 폴더의 grok_downloads/stream에 저장되며(경로는 설정에서 변경 가능), 파일 이름은 grok_stream_ 뒤에 캡처 시각이 붙습니다. '캡처 삭제'는 목록을 비웁니다.

탭을 새로고침하거나 닫으면 캡처한 이미지가 남아 있나요?

남지 않습니다. 캡처한 이미지는 다운로드할 때까지 해당 grok.com 탭의 메모리에만 보관되므로, 새로고침하거나 탭을 닫기 전에 먼저 다운로드하세요.

캡처를 일시 중지했다가 다시 시작할 수 있나요?

네. '활성화' 스위치를 끄면 새 이미지 감시가 멈추고, 이미 캡처한 이미지는 목록에 남습니다. 다시 켜면 같은 목록에 계속 추가됩니다.

같은 이미지가 두 번 캡처되나요?

아니요. 새 이미지는 이번 세션에서 이미 캡처한 이미지와 비교되므로, 다시 나타난 이미지가 중복으로 추가되지 않습니다.

스트림 캡처는 무료인가요?

아니요, 스트림 캡처는 PRO 기능입니다. 무료 버전은 즐겨찾기, 태그 또는 라이브러리의 최근 7일 분량에서 이미지를 일괄 다운로드합니다. PRO($4.99 일회성 결제, 평생 라이선스)로 업그레이드하면 스트림 캡처와 함께 동영상 다운로드, 스토리 모드 내보내기, 프로젝트 다운로드, 무제한 Video Gen Queue를 사용할 수 있습니다.
