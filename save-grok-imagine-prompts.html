How-to guide

Save Grok Imagine videos with their prompts

Put the prompt in each filename, use your own naming pattern, or keep the full prompt in a .json file next to every download.

Add to Chrome See PRO pricing

Updated November 28, 2026 · written for extension version 2.6.3

Short answer

Install GrokMediaDownloader and open grok.com/library. In the popup, open ⚙️ Settings and pick Prompt Based under 📝 Filename Format, or a Custom Template that contains {prompt}. Tick 📋 Save Metadata to also save a .json file with the full prompt next to every file. Then click 1. Generate List and 2. Start Download. The naming and metadata options are free and work for images; downloading videos needs PRO.

Three ways to keep a prompt

You can combine all three. Each one is a setting in the extension popup, and none of them changes anything on Grok.

Prompt in the filename

The Prompt Based format names files like img_20261128143015_a_red_fox_in_fresh_snow_1a2b3c4d.jpg, so you can search your disk by prompt.

Your own naming pattern

A Custom Template combines tokens such as {date}, {prompt} and {shortid} into names that fit the way you sort files.

The full prompt in a .json file

Save Metadata writes a small .json file beside each download with the complete prompt, the creation time, the ID and, for videos, the quality that was saved.

Step by step

  1. 1

    Step 1: Install the extension and open Grok

    Add GrokMediaDownloader from the Chrome Web Store and pin its icon to the toolbar. Sign in to Grok in the same Chrome profile.

    Open grok.com/library. Since version 2.6.3 any grok.com page works. On a tab outside grok.com, the popup asks you to open Grok first.

  2. 2

    Step 2: Choose a filename format

    Click the extension icon to open the popup and expand ⚙️ Settings. If you have PRO and use the compact view, click More at the top of the popup first, because the compact view hides Settings.

    Under 📝 Filename Format, pick Prompt Based for names built from the date, time and prompt. Pick Custom Template to decide the order yourself, then type a pattern into the Images: and Videos: fields. Grok Native keeps short ID-based names without the prompt.

    Settings are saved as soon as you change them.

  3. 3

    Step 3: Turn on Save Metadata for the full prompt

    In the same section, tick 📋 Save Metadata ("Save .json file with image/video info (prompt, resolution, etc.)"). Each image or video then gets a .json file with the same name next to it.

    Filenames shorten long prompts, so the .json file is where the complete prompt is kept. It works with any filename format, including Grok Native.

  4. 4

    Step 4: Pick a source and generate the list

    In 📥 Download Source & Filter, choose 📦 All Generated Media (by Conversation) (the default, your whole library), 🌟 Favorite or 🏷️ Tag. Under 🎬 Media Types, keep 🖼️ Images ticked. 🎬 Videos (Pro) can be ticked with PRO.

    Click 1. Generate List. When your settings use prompts, the button shows 📝 Fetching prompts with a counter while the extension looks up each prompt in the conversation that created the item. A video without a prompt of its own takes the prompt of the image it was made from. Prompts that were found once are kept in a local cache, so later runs finish faster.

    When the scan ends, the popup opens a 📊 Download Summary dialog: how many images and videos will be downloaded, the videos split by quality, and the question "Start download?". OK starts the download right away. Cancel closes the dialog and leaves 2. Start Download enabled, so you can check your settings first; the screenshot below shows that state.

  5. 5

    Step 5: Start the download

    If you clicked Cancel in the summary, click 2. Start Download now. A progress bar shows how far the run is and estimates the time left. ⏹ Stop Download pauses the run and ▶ Continue Download picks it up again.

    The extension keeps a download history for each source, so a second run skips files you already saved. To stay within Grok's limits, the extension pauses after every 250 videos, for 3 minutes by default (adjustable in ⚙️ Settings), and then continues by itself.

  6. 6

    Step 6: Find the files and their prompts

    Files are saved in Chrome's Downloads folder under grok_downloads/. Favorites go to images/ and videos/, tags to tags/ with one folder per tag, and the whole library to conversations/, with one folder per conversation named after its date, title or prompt, and a short ID. You can change these paths in ⚙️ Settings.

    With Save Metadata on, every media file sits next to its .json file.

What Prompt Based names look like

The exact pattern depends on the download source. These examples use the prompt "a red fox in fresh snow".

SourceImageVideo
📦 All Generated Mediaimg_20261128143015_a_red_fox_in_fresh_snow_1a2b3c4d.jpgvid_20261128143015_a_red_fox_in_fresh_snow_9e8d7c6b.mp4
🌟 Favorite, 🏷️ Tagimg_20261128143015_a_red_fox_in_fresh_snow.jpghd_20261128143015_a_red_fox_in_fresh_snow.mp4

The 14-digit number is the creation date and time (YYYYMMDDHHmmss) in your computer's time zone.

In the whole library, the last 8 characters of the item's ID are added at the end. Two items with the same prompt created in the same second therefore never share a name.

Videos from Favorites and tags start with hd_ or sd_, the quality that was downloaded.

Custom Template tokens

Choose Custom Template and type one pattern for images and one for videos. The extension replaces each token and adds the file extension itself.

TokenBecomesExample
{date}Creation date2026-11-28
{time}Creation time (hours, minutes, seconds)143015
{datetime}Date and time together2026-11-28_143015
{id}The item's full Grok IDthe full ID
{shortid}The last 8 characters of the ID1a2b3c4d
{prompt}The prompt, cleaned for filenames and cut to 80 charactersa_red_fox_in_fresh_snow
{quality}hd or sd for videos from Favorites and tags; empty for images and for the whole libraryhd

Example: {date}_{prompt}_{shortid} as the image pattern gives 2026-11-28_a_red_fox_in_fresh_snow_1a2b3c4d.jpg.

Unknown tokens are removed. If a pattern contains none of {id}, {shortid} or {datetime}, the popup warns "⚠ No unique token — files may overwrite each other". Add one of them so every file keeps its own name.

An item without a prompt gets part of its ID in place of {prompt}. If a template field is left empty, the file is named after its ID.

What the .json file contains

With 📋 Save Metadata on, every downloaded file gets a .json file with the same name. It stores the prompt as recorded, including characters that cannot appear in filenames. The fields are:

  • prompt and originalPrompt: the prompt text
  • createTime: when the item was created; downloadedAt: when you saved it
  • id, type, url and filename: which item this is and where it came from
  • userId: your Grok account ID
  • for videos also hdUrl, detailUrl and downloadedQuality (hd or sd)

A shortened example for a video:

{
  "id": "…",
  "type": "video",
  "url": "…",
  "filename": "vid_20261128143015_a_red_fox_in_fresh_snow_9e8d7c6b.mp4",
  "createTime": "2026-11-28T14:30:15.000Z",
  "prompt": "a red fox in fresh snow, slow camera pan",
  "originalPrompt": "a red fox in fresh snow, slow camera pan",
  "downloadedQuality": "hd",
  "downloadedAt": "2026-11-28T15:02:41.000Z"
}

Because the file includes your Grok user ID, you may want to leave the .json files out when you share a folder publicly.

Project folders and metadata.json (Favorite source)

With the 🌟 Favorite source, 📂 Download Mode offers Group by Project. Each project folder holds the source image, the videos generated from it, and one metadata.json. The folder is named after the date, the prompt and a short ID, for example 20261128_a_red_fox_in_fresh_snow_1a2b3c4d.

metadata.json lists the folder's prompt and creation time, the source image, and each generated video with its own prompt and download links, plus a count of images and videos. It is written for every project folder, whether or not Save Metadata is on. Files you already downloaded in Standard mode are skipped; to get complete project folders, the popup suggests clearing the download history first.

Project folders are only offered for the Favorite source, and since they are built around videos they are most useful with PRO. Since Grok's July 2026 change, newly generated media is missing from Favorites for many accounts. For those items, use 📦 All Generated Media: each conversation folder already keeps an image and the videos made from it together.

Filename length and character rules

Prompts are written by people, not for file systems, so the extension cleans them before using them in a name:

  • Characters that are not safe in filenames ( \ / : * ? " < > | ), line breaks and tabs are removed.
  • Spaces become underscores, and repeated underscores are merged into one.
  • Long prompts are cut: to 100 characters in Prompt Based names from the whole library, 120 from Favorites and tags, 80 for the {prompt} token and 90 in project folder names.
  • Image references written as @ followed by an ID, and option flags at the end of a prompt such as --mode=…, are left out of names. The .json file keeps the prompt as it was stored.
  • Letters outside the Latin alphabet, such as Chinese, Japanese or Korean, stay as they are.
  • Items without a prompt, such as images you uploaded yourself, are named after their ID.

None of these rules touches the .json file, so with Save Metadata on the full prompt is always kept.

If the popup asks you to regenerate the list

Looking up prompts takes time, so the extension only does it when your settings need them: Prompt Based names, a Custom Template with {prompt}, or Save Metadata.

If you generated the list with Grok Native names and no metadata, and then switch one of these on, the popup shows ⚠️ Prompt-based filenames/metadata need prompts — please regenerate the list. Click 1. Generate List again before you start. Otherwise the new files would be saved without their prompts.

Troubleshooting

The problems people run into most when saving prompts, and how to fix each one.

Files are named with an ID instead of the prompt
There are three common reasons. The item has no prompt, for example an image you uploaded. The list was generated before you changed the filename settings, so generate it again. Or the list came from an older extension version: update the extension, then generate the list again. Chrome updates extensions automatically; to force it, open chrome://extensions, turn on Developer mode and click Update.
The popup says prompt-based filenames/metadata need prompts
Your settings now use prompts, but the current list was built without them. Click 1. Generate List again, then 2. Start Download.
The Videos checkbox is greyed out with a lock
Video downloads are a PRO feature. In the free version you can download images with every naming and metadata option. PRO is a one-time $4.99 purchase (pricing). After buying, paste your GMD-… key into 🔑 License in the popup.
Generate List stays on "Fetching prompts" for a long time
The first run looks up the prompt of every conversation in the list, which takes a while on a large library. If Grok answers these lookups with an error such as HTTP 429, the extension slows down and retries automatically. Later runs use the local prompt cache and are much quicker. With PRO you can also narrow a large scan with the date filter.
Two files ended up with the same name
Your Custom Template has no unique token. Add {shortid}, {id} or {datetime}. Prompt Based names from the whole library already end with a short ID.
I changed the format, but files I downloaded earlier keep their old names
The extension does not rename files that are already on your disk, and its download history skips them. To save them again with the new names, open 🧹 Clear Actions and clear the history of that source: Clear Conversation History for the whole library, Reset Download History for Favorites, or Clear Tag History for tags. Then generate the list and start again. Clearing a history deletes nothing on Grok or on disk.

Frequently asked questions

Can I download Grok Imagine videos with their prompts automatically?

Yes. In ⚙️ Settings, choose Prompt Based or a Custom Template with {prompt}, and turn on 📋 Save Metadata if you also want the full prompt in a .json file. Every file you download after that carries its prompt. Video downloads need PRO; images work in the free version.

Is saving prompts free?

Yes. The filename formats, Custom Templates and .json files are free for everyone. PRO, a one-time $4.99 purchase, adds video downloads, your library beyond the last 7 days and the date filter. Details are on the pricing page.

Where do I find the full prompt if the filename is shortened?

In the .json file next to the media file, which is created when 📋 Save Metadata is on. Filenames are cut to stay usable, while the .json file stores the prompt as it was recorded.

Does it work with prompts in Chinese, Japanese or other languages?

Yes. Only characters that are not safe in filenames are removed. Chinese, Japanese, Korean and accented letters stay in the name as typed.

Which prompt does a video get if it was made from an image?

Its own animation prompt when it has one. A video without a prompt of its own takes the prompt of the image it was made from, so it still gets a meaningful name.

Are my prompts uploaded anywhere?

No. The extension runs in your browser and saves files straight from Grok to your disk. The only outside service it contacts is Kario Studio's license server, to check a PRO key.
