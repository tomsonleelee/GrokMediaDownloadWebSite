Grok のアップデート後にダウンロードボタンが消えた・押せないときの対処法

11月のアップデート後に Grok を開いたら、ダウンロードボタンがなくなっていた、またはグレーアウトしていた。Grok Media Downloader を使っているなら、たいていは拡張機能を1回更新するだけで直ります。このガイドでは、Grok 側で何が変わったのか、2.6.3より前のバージョンが動かなくなった理由、そして更新して再びダウンロードできるようにする方法を説明します。

結論

2026年11月12～13日、Grok は Imagine をメインアプリに統合し、一部のアカウントでは /imagine のページが Library かトップページへリダイレクトされるようになりました。2.6.3より前の Grok Media Downloader は /imagine のページでしか1. リスト生成と2. ダウンロード開始を有効にしなかったため、ボタンがグレーアウトしたままになりました。

バージョン2.6.3以降に更新してください。Chrome は数時間以内に自動で更新します。今すぐ更新するには、chrome://extensions を開き、デベロッパー モードをオンにして更新をクリックします。その後 grok.com/library を開いてタブを再読み込みし、これまでどおり拡張機能を使ってください。

Chromeに追加 2.6.3の変更内容

このガイドで扱うダウンロードボタン

このガイドで扱うのは、ブラウザ拡張機能 Grok Media Downloader のボタンです。Grok 自体に組み込まれたダウンロード機能を含め、Grok の画面は私たちの管理外で、いつ変わってもおかしくありません。そちらについては Grok のヘルプを確認してください。

2026年11月に Grok で変わったこと

2026年11月12日と13日、Grok は Imagine をメインの Grok アプリに統合しました。サイドバーには Library が表示されるようになり、生成した画像や動画はそこに一覧表示されます。一部のアカウントでは Imagine タブがなくなり、grok.com/imagine/saved を含む /imagine のページは Library かトップページにリダイレクトされます。Grok はアカウントを1つずつ順に移行しているため、まだ Imagine タブが残っているアカウントもあります。そのため、同じ日でも人によって画面の構成が違うことがあります。

Imagine のページを前提に作られた拡張機能にとっては、見た目の変化よりもリダイレクトのほうが大きな問題でした。その理由は次のセクションで説明します。

拡張機能のボタンがグレーアウトした理由

2.6.3より前の Grok Media Downloader は、アクティブなタブのアドレスを確認し、grok.com/imagine のページでだけメインのボタンを有効にしていました。Grok がこれらのページをリダイレクトし始めると、ユーザーがたどり着けるどのページでもこのチェックが通らなくなりました。ポップアップは1. リスト生成と2. ダウンロード開始をグレーアウトしたまま、次のメッセージを表示しました。

「Grok Imagine のお気に入りページで使用してください。」

その下のリンクお気に入りへ →は grok.com/imagine/saved を開きますが、そこでもまたリダイレクトされます。古いバージョンのままでは先に進む方法がなく、Grok のアップデートと一緒にダウンロードボタンが消えたように見えたのです。

2026年11月23日にリリースされたバージョン2.6.3で、この制限はなくなりました。現在の拡張機能はどの grok.com のページでも動作し、おすすめは grok.com/library です。拡張機能は表示中のページではなくライブラリを直接読み取るので、どの Grok のページを開いていてもダウンロードされる内容は変わりません。

バージョン別：ボタンが使えるページ

拡張機能のバージョンボタンが有効になるページ
2.6.3より前grok.com/imagine のページのみ
2.6.3以降すべての grok.com のページ（grok.com/library を推奨）

アップデートは無料版・PRO を問わず、誰でも無料で受け取れます。

直し方

作業は数分で終わります。拡張機能を削除する必要はなく、設定、ダウンロード履歴、PRO ライセンスはそのまま残ります。

  1. 1

    拡張機能のバージョンを確認する

    アドレスバーに chrome://extensions と入力して Enter キーを押します。Grok Media Downloader を探し、カードに表示されたバージョン番号を確認します。2.6.3以上なら、すでに修正済みです。手順4へ進んでください。

  2. 2

    拡張機能を更新する

    Chrome は拡張機能を自動で更新します。通常は新しいリリースから数時間以内です。すぐに更新したい場合は、chrome://extensions の右上にあるスイッチでデベロッパー モードをオンにし、ページ上部に表示される更新ボタンをクリックします。Chrome がすべての拡張機能を確認し、保留中の更新をインストールします。

  3. 3

    新しいバージョンを確認する

    カードの表示が2.6.3以降になっていることを確認します。デベロッパー モードは更新ボタンを使うためだけに必要なので、終わったらオフに戻してかまいません。

  4. 4

    grok.com/library を開いて再読み込みする

    grok.com/library、またはほかの grok.com のページを開き、更新後の拡張機能がページに接続できるようタブを再読み込みします。サインインしていることも確認してください。

  5. 5

    ポップアップを開いてボタンを確認する

    Grok Media Downloader のアイコンをクリックします。ポップアップには上から順に次の項目が並んでいます。

    • 📊 ステータス：画像と、画質別の動画の件数。スキャン後に表示されます。
    • 🎬 メディアタイプ：画像。動画には PRO が必要です。
    • 📥 ダウンロード元とフィルター：リストの取得元と、PRO の日付フィルター。
    • 1. リスト生成：どの grok.com ページでもクリックできるようになっています。
    • 2. ダウンロード開始：ダウンロード対象のファイルを含むリストができると有効になります。
  6. 6

    いつもどおりダウンロードする

    ダウンロード元を選び、1. リスト生成をクリックします。スキャンが終わると📊 ダウンロード概要のダイアログが「ダウンロードを開始しますか？」と確認します。「OK」ですぐに開始するか、「キャンセル」を選んで、準備ができたら2. ダウンロード開始をクリックします。古いバージョンでダウンロードしたファイルはスキップされます。最近のメディアがリストに入っていない場合は、🌟 お気に入りではなく📦 すべての生成メディア（会話別）を使ってください。理由はGrok のお気に入りが表示されない？ライブラリをバックアップする方法で説明しています。このパソコンにまだ拡張機能が入っていない場合は、Chromeウェブストアから入手できます。

2.6.3以降で grok.com を開くよう求めるメッセージが出る場合

バージョン2.6.3でも、ボタンがグレーアウトする状況が1つだけあります。アクティブなタブが grok.com のページではないとき、たとえばニュースサイトや空の新しいタブでポップアップを開いたときです。その場合は次のように表示されます。

「grok.com（ライブラリまたは Imagine の保存済みページ）を開いてからもう一度お試しください。」

メッセージの下にあるGrok ライブラリへ →をクリックするか、grok.com のタブに切り替えてから、もう一度ポップアップを開いてください。拡張機能は常に現在のウィンドウのアクティブなタブを対象にするので、複数のウィンドウを開いている場合は、Grok を表示しているウィンドウでアイコンをクリックしてください。

トラブルシューティング

更新してもボタンが使えない場合は、たいてい次のどれかが原因です。

更新してもボタンがグレーアウトしたまま

アクティブなタブが本当に grok.com のページか確認し、そのタブを再読み込みしてから、もう一度ポップアップを開いてください。ポップアップに「grok.com（ライブラリまたは Imagine の保存済みページ）を開いてからもう一度お試しください。」と表示される場合は、別のタブかウィンドウを見ています。chrome://extensions に表示されたバージョンがまだ2.6.3未満なら、更新がまだ届いていません。

「更新」をクリックしても2.6.3がインストールされない

Chrome が新しいリリースを取得するまでに時間がかかることがあります。数時間待ってから、もう一度「更新」をクリックしてください。最後の手段として、拡張機能を削除し、Chromeウェブストアから追加し直す方法もあります。削除すると拡張機能のローカルのダウンロード履歴が消えるため、次回の実行ではファイルがもう一度ダウンロードされます。また PRO ユーザーは、再度アクティベートが必要になる場合に備えて、ライセンスキーを手元に用意しておいてください。

「2. ダウンロード開始」だけがグレーアウトしている

リストができるまでは、それが正常な動作です。先に「1. リスト生成」をクリックしてください。リストを生成した後でフィルターを変えたり、プロンプトが必要なファイル名設定に切り替えたりした場合は、ポップアップがリストの再生成を求め、再生成するまで「2. ダウンロード開始」はグレーアウトしたままです。スキャンの実行中も、両方のボタンが無効になります。

ポップアップに「生成に失敗しました」と表示される

grok.com にサインインしていることを確認し、タブを再読み込みしてからもう一度お試しください。

Grok で Imagine や保存したメディアが見つからない

11月の変更が適用されたアカウントでは、メディアは Grok のサイドバーにある Library（grok.com/library）にあります。Grok が自分のページをどこに置くかは Grok が決めることなので、そこで見つからない場合は Grok のヘルプを確認してください。

よくある質問

Grok のアップデート後にダウンロードボタンが消えたのはなぜですか？

2026年11月12～13日、Grok は Imagine をメインアプリに統合し、一部のアカウントでは /imagine のページが Library かトップページにリダイレクトされるようになりました。2.6.3より前の Grok Media Downloader は /imagine のページでしか「1. リスト生成」と「2. ダウンロード開始」を有効にしなかったため、ボタンがグレーアウトしたままになりました。バージョン2.6.3はどの grok.com のページでも動作します。

Grok Media Downloader のどのバージョンで直りますか？無料ですか？

2026年11月23日にリリースされたバージョン2.6.3と、それ以降のすべてのバージョンです。アップデートは無料版・PRO を問わず、すべてのユーザーが無料で受け取れます。Chrome が自動でインストールしますが、chrome://extensions でデベロッパー モードをオンにして「更新」をクリックすれば、すぐに更新することもできます。

拡張機能はどの Grok のページで使えばいいですか？

おすすめは grok.com/library です。2.6.3以降はどの grok.com のページでも動作し、grok.com/imagine/saved が残っているアカウントではそこでも使えます。拡張機能のアイコンをクリックするときは、Grok のタブをアクティブにしておいてください。

まだ Imagine タブがあるアカウントでも、更新は必要ですか？

はい、更新しておく価値があります。Grok はアカウントを1つずつ移行しているため、いつ自分のアカウントでリダイレクトが始まってもおかしくありません。バージョン2.6.3は Imagine のページでも Library でも同じように動作します。

更新すると、設定、ダウンロード履歴、ライセンスは消えますか？

消えません。Chrome は拡張機能をその場で更新するので、設定、ダウンロード履歴、有効化済みの PRO ライセンスはそのまま残ります。

このガイドは Grok 自体のダウンロードボタンも対象ですか？

いいえ。このガイドは Grok Media Downloader 拡張機能についてのものです。Grok の画面は私たちの管理外で、時とともに変わります。Grok に組み込まれたダウンロード機能については、Grok のヘルプを確認してください。
