Video Gen Queue

자동 동영상 생성 큐

사이드 패널에서 동영상을 일괄 생성합니다. 4가지 생성 모드, 설정한 한도까지의 자동 재시도, Grok이 속도를 늦추라고 할 때 대기열을 멈추는 속도 제한 감지를 지원합니다.

핵심 기능

Video Gen Queue는 완전한 자동 동영상 생성 도구 체인을 제공합니다

🔄

자동 재시도

검열되거나 실패한 시도는 항목마다 설정한 재시도 한도까지 자동으로 다시 시도합니다.

📋

일괄 큐 추가

'최근 게시물 일괄 추가'는 Grok 즐겨찾기 중 최근 1~72시간 안에 만든 이미지 게시물을 하나의 공통 프롬프트로 한꺼번에 추가합니다.

🎨

4가지 생성 모드

Custom/Normal/Fun/Spicy 모드로 다양한 크리에이티브 스타일에 대응.

🛡️

속도 제한 감지

Grok의 속도 제한 응답(HTTP 429)을 감지해 대기열을 멈춥니다. 잠시 기다렸다가 다시 시작하세요.

Video Gen Queue 사용 방법

5단계로 동영상 생성을 자동화

1

Grok Imagine 탐색

grok.com에서 이미지를 탐색 및 생성하고, 동영상으로 만들고 싶은 Posts를 찾으세요.

2

큐에 추가

게시물의 떠 있는 🎯 버튼을 누르거나, '최근 게시물 일괄 추가'로 즐겨찾기 중 최근 1~72시간 안에 만든 이미지 게시물을 추가하세요.

3

파라미터 설정

모드(Custom/Normal/Fun/Spicy), 시간(6s/10s), 해상도(480p/720p), 목표 횟수, 재시도 제한을 선택.

4

생성 시작

Start를 클릭. 시스템이 각 Post 페이지로 자동 이동하여 생성 요청을 순차적으로 전송.

5

결과 수집

각 항목은 목표나 재시도 한도에 도달하면 멈추고, 패널에 성공·실패 횟수가 표시됩니다. 새 동영상은 팝업으로 다운로드하세요(동영상 다운로드는 PRO 필요).

기술 하이라이트

Chrome Side Panel API

Chrome 최신 Side Panel API로 상주형 워크스페이스를 제공. 메인 페이지 탐색을 방해하지 않습니다.

IndexedDB 영구 저장

큐 데이터와 프롬프트 통계를 IndexedDB에 독립적으로 저장. 브라우저를 닫아도 데이터가 사라지지 않습니다.

Fetch Interceptor

페이지 안에서 Grok의 응답을 가로채 생성 결과를 읽으며, 시간 초과(기본 180초, 30~600초로 조정 가능)가 있어 한 번 멈춘 시도가 대기열 전체를 막지 않습니다.

Free/Pro 티어

무료 사용자는 50회, PRO 사용자는 무제한. 다양한 사용 니즈에 대응.

4가지 생성 모드

생성 모드 상세 설명

각 대기열 항목마다 다른 모드를 사용할 수 있습니다. 조합하여 각 비디오에 원하는 스타일을 적용하세요.

Custom

나만의 프롬프트를 입력하여 완전한 창작 주도권을 확보하세요. 원하는 내용을 정확히 작성하면 대기열이 선택한 각 이미지에 대해 실행합니다.

Normal

Grok의 Normal 프리셋. 프롬프트를 입력할 필요가 없습니다.

Fun

Grok의 Fun 프리셋. 프롬프트를 입력할 필요가 없습니다.

Spicy

Grok의 Spicy 프리셋. 프롬프트를 입력할 필요가 없으며, 패널에 Grok이 이 요청을 표시할 수 있다는 경고가 나옵니다.

대기열 항목마다 다른 모드를 쓸 수 있습니다. 검열된 시도는 항목별 재시도 한도까지 다시 시도한 뒤 다음 항목으로 넘어갑니다.

자주 묻는 질문

Video Gen Queue에 관한 모든 질문에 답변드립니다

Video Gen Queue란 무엇이며 어떻게 작동하나요?

Video Gen Queue는 확장 프로그램의 사이드 패널에서 Grok 동영상 생성을 자동화하는 기능입니다. 이미지 게시물을 대기열에 추가하고 모드(Custom, Normal, Fun, Spicy)와 게시물당 성공시킬 동영상 수를 고르면, 확장 프로그램이 grok.com에서 각 게시물을 차례로 열어 프롬프트를 입력하고 제출합니다. 검열되거나 실패한 시도는 최대 재시도 횟수까지 다시 시도한 뒤 다음 게시물로 넘어갑니다. 무료 버전은 50회, PRO는 무제한입니다.

게시물을 대기열에 추가하려면 어떻게 하나요?

팝업에서 🎯 Queue를 눌러 패널을 엽니다. Grok 게시물 페이지에서는 떠 있는 🎯 버튼으로 프롬프트와 옵션을 설정해 그 게시물을 추가할 수 있고, 패널의 '항목 추가'에 게시물 ID나 URL을 붙여넣을 수도 있습니다. '최근 게시물 일괄 추가'는 Grok 즐겨찾기 중 최근 1~72시간 안에 만든 이미지 게시물을 하나의 공통 프롬프트로 한꺼번에 추가합니다. 2026년 7월 Grok 변경 이후에는 새 이미지가 즐겨찾기에 없을 수 있습니다.

항목마다 어떤 설정을 할 수 있나요?

모드(Custom, Normal, Fun, Spicy), 프롬프트(Custom은 필수, 나머지 모드는 비워 둬도 됨), 성공 목표, 최대 재시도, 영상 길이(6초 또는 10초), 해상도(480p 또는 720p)입니다. 10초와 720p는 SuperGrok이 필요하며, 자격이 없는 계정이면 Grok이 요청을 거부하거나 표시할 수 있습니다.

각 항목의 진행 상황을 볼 수 있나요?

네. 각 항목에 대기, 진행 중, 완료, 실패 상태와 목표 대비 성공·실패 횟수가 표시됩니다. '프롬프트 통계'에는 프롬프트별 성공 횟수와 검열된 횟수가 기록되어 어떤 프롬프트가 잘 되는지 알 수 있습니다.

Grok 속도 제한에 걸리거나 생성이 멈추면 어떻게 되나요?

Grok이 속도 제한 오류(HTTP 429)를 보내면 대기열이 멈추고 메시지를 표시합니다. 잠시 기다린 뒤 '시작'을 다시 누르세요. 생성 시간 초과(기본 180초, 설정에서 30~600초로 변경 가능) 안에 결과가 오지 않으면 그 시도는 오류로 기록되고 대기열은 다음 항목으로 넘어갑니다.

사이드 패널을 닫거나 페이지를 새로고침하면 대기열이 사라지나요?

아니요. 대기열 항목과 프롬프트 통계는 브라우저의 IndexedDB에 저장되므로 패널을 닫거나 grok.com을 새로고침해도 남아 있고, 새로고침 후에는 처리가 다시 이어집니다. 대기열이 실행되는 동안에는 브라우저를 열어 두고 Grok 탭을 게시물 페이지에 두세요.

Video Gen Queue는 무료인가요?

네, 횟수 제한이 있습니다. 무료 버전은 50회까지이며, 1회는 대기열을 통해 Grok이 생성에 성공한 동영상 1개입니다. 검열되거나 실패한 시도는 세지 않습니다. PRO($4.99 일회성 결제, 평생 라이선스)는 무제한이며 동영상 다운로드, 스트림 캡처, 스토리 모드 내보내기, 프로젝트 다운로드도 함께 사용할 수 있습니다.
