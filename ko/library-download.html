Grok Imagine에서 만든 모든 이미지와 동영상을 한 번의 실행으로 컴퓨터에 저장합니다. 대화마다 폴더 하나로 묶이고, 파일 이름에는 그것을 만든 프롬프트가 들어갑니다.

간단한 답

Grok Media Downloader를 설치하고 grok.com/library를 연 다음 확장 프로그램 아이콘을 클릭하세요. 전부 받으려면 다운로드 소스를 📦 모든 생성 미디어(대화별)로 그대로 두고, 저장해 둔 항목만 받으려면 🌟 즐겨찾기를 고르세요. 1. 목록 생성을 클릭하고, 이어서 나타나는 다운로드 요약에서 '확인'을 누르세요(나중에 2. 다운로드 시작을 눌러도 됩니다). 파일은 다운로드 폴더의 grok_downloads/ 아래에 대화별 폴더로 저장됩니다.

무료 버전은 최근 7일간의 이미지를 다운로드합니다. PRO를 사용하면 동영상과 전체 라이브러리까지 받을 수 있습니다.

시작하기 전에: Grok이 2026년 7월에 미디어 백엔드를 바꿨습니다

Grok은 새로운 "대화 + 에셋" 모델로 전환했습니다. 그 이후 많은 계정에서 즐겨찾기 목록, 즉 Grok의 저장됨(Saved) 페이지에 새로 생성한 미디어가 더 이상 추가되지 않아, 즐겨찾기만 다운로드하면 최근 작업이 빠질 수 있습니다. "즐겨찾기를 전부" 받고 싶은 분들이 실제로 원하는 것은 대개 자신이 만든 모든 것입니다. 📦 모든 생성 미디어(대화별) 소스가 읽는 것이 바로 그것, 저장 여부와 관계없는 라이브러리 전체입니다. v2.5.1부터 기본 소스로 설정되어 있습니다.

이전 확장 프로그램 버전이 의존하던 엔드포인트는 더 이상 저장됨 및 미디어 라이브러리 화면에 쓰이지 않습니다. 즉 v2.5.0 이전 버전은 새로 생성된 이미지와 동영상을 감지할 수 없습니다. v2.5.0은 새 백엔드에 맞춘 전면 대응이며, 전체 라이브러리 다운로드는 이 새 API 덕분에 가능해진 기능입니다. 또한 2026년 11월 12~13일에 Grok이 Imagine을 Grok 메인 앱에 통합하면서, 2.6.3 이전 버전에서는 버튼이 회색으로 비활성화되었습니다. 2.6.3 이상 버전을 사용하세요. 회색으로 비활성화된 버튼을 해결하는 방법은 여기에서 확인하세요.

1. 업데이트

Chrome 웹 스토어에서 설치 또는 업데이트: 2.6.3 이상 버전

2. 다시 로드

chrome://extensions에서 확장 프로그램을 다시 로드한 뒤 Grok 탭 새로 고침

3. 재생성

다운로드 목록을 한 번 다시 생성해 새 명명 규칙, 병합된 태그, 생성 대화에서 되찾아온 프롬프트를 적용

단계별 안내: Grok Imagine 라이브러리 전체 다운로드

확장 프로그램만 설치하면 다운로드 자체는 클릭 두 번이면 끝납니다. 스크린샷은 한국어로 표시된 팝업이며, 확장 프로그램은 모든 언어에서 같은 화면 구성을 사용합니다.

  1. 1

    Grok Media Downloader를 설치하고 고정하기

    Chrome 웹 스토어 페이지를 열고 Chrome에 추가를 클릭합니다. 그런 다음 Chrome 도구 모음의 퍼즐 조각 아이콘을 클릭해 Grok Media Downloader를 고정하면 아이콘이 항상 보입니다. 이미 설치했다면 chrome://extensions를 열어 버전이 2.6.3 이상인지 확인하세요. Chrome은 몇 시간 안에 확장 프로그램을 자동으로 업데이트합니다. 바로 업데이트하려면 같은 페이지에서 개발자 모드를 켜고 업데이트를 클릭하세요.

  2. 2

    grok.com/library 열기

    Grok에 로그인하고 grok.com/library를 엽니다. 2.6.3 버전부터 확장 프로그램은 모든 grok.com 페이지에서 작동하며, 라이브러리에서 시작하는 것이 편합니다. 계정에 아직 Imagine 저장됨 페이지(grok.com/imagine/saved)가 있다면 그곳에서도 사용할 수 있습니다. grok.com이 아닌 탭에서는 팝업의 버튼이 비활성화되고 "grok.com(라이브러리 또는 Imagine 저장됨 페이지)을 연 다음 다시 시도하세요."라는 메시지와 함께 Grok 라이브러리로 이동 → 링크가 표시됩니다.

  3. 3

    확장 프로그램 아이콘을 클릭해 팝업 열기

    팝업에는 위에서부터 상태 패널, 다운로드할 미디어 유형, 🎯 다운로드 소스 선택기, 그리고 실제 작업을 하는 두 버튼 1. 목록 생성과 2. 다운로드 시작이 있습니다. 🎬 미디어 유형 섹션에서 이미지에 체크하세요. 비디오 (Pro) 체크박스는 PRO 라이선스가 있어야 사용할 수 있으며, 무료 버전은 이미지만 다운로드합니다.

  4. 4

    다운로드할 대상 고르기

    다운로드 소스 선택기에서 세 가지 소스 중 하나를 고릅니다.

    • 📦 모든 생성 미디어(대화별)는 라이브러리 전체이며, 대화마다 폴더 하나로 정리됩니다. 기본값이고 전체 백업에 알맞은 선택입니다. 무료 버전에서는 최근 7일이 대상이며, 팝업의 선택기 아래에도 그렇게 안내됩니다. PRO에서는 이 제한이 없습니다.
    • 🌟 즐겨찾기는 Grok에서 저장한 항목만 대상으로 합니다. 2026년 7월 이후 이 목록에는 새로 생성한 미디어가 빠질 수 있으며, 이 소스를 고르면 팝업에 경고가 표시됩니다.
    • 🏷️ 태그는 Grok 태그(컬렉션이라고도 함) 하나를 대상으로 합니다. 나타나는 목록에서 태그를 고르세요.

    PRO에서는 즐겨찾기나 모든 생성 미디어의 스캔 범위를 날짜 필터로 좁힐 수도 있습니다. 날짜 범위 또는 최근 N시간 중에서 고르면 됩니다. 태그 소스에는 날짜 필터가 없습니다.

  5. 5

    1. 목록 생성 클릭

    확장 프로그램이 소스를 최신순으로 스캔합니다. 전체 라이브러리라면 각 동영상에 어떤 화질 단계가 있는지 확인하고 대화 폴더도 준비하며, 지금 어느 단계가 진행 중인지 버튼에 표시됩니다. 스캔이 끝나면 📊 다운로드 요약 대화상자가 열려 다운로드할 이미지와 동영상(동영상은 1080p, HD, 720p, SD별)과 이미 완료된 수를 보여 줍니다. 마지막의 '다운로드를 시작하시겠습니까?'에서 '확인'을 누르면 바로 다운로드가 시작되고, '취소'를 누르면 대화상자가 닫히면서 상태 패널에 개수가 표시되고 2. 다운로드 시작을 누를 수 있는 상태로 남습니다. 이미 다운로드 기록에 있는 항목은 다시 세지 않습니다. 나중에 프롬프트가 필요한 파일명이나 메타데이터 설정을 바꾸면 팝업이 목록을 다시 생성하라고 안내합니다.

  6. 6

    다운로드 시작하기

    다운로드 요약에서 '확인'을 누르세요. 앞에서 취소했다면 2. 다운로드 시작을 클릭하면 같은 요약이 다시 나타납니다. 다운로드할 동영상이 250개를 넘으면 250개마다 일시정지한다는 안내도 요약에 함께 표시됩니다. 진행 표시줄에는 완료된 파일 수와 남은 예상 시간이 표시됩니다. 실행 중에는 브라우저와 grok.com 탭을 열어 두세요. 잠시 멈추려면 ⏹ 다운로드 중지를 클릭하세요. 버튼이 ▶ 다운로드 계속으로 바뀌고, 누르면 멈춘 곳부터 이어서 받습니다. 250개마다의 일시정지는 기본 3분이며, ⚙️ 설정의 ⏱️ 속도 제한 대기에서 1~60분으로 바꿀 수 있습니다. 시간이 지나면 자동으로 다시 진행합니다.

  7. 7

    파일 찾기

    파일은 Chrome 다운로드 폴더 안의 grok_downloads 폴더에 저장되며, 하위 폴더는 다음과 같습니다.

    • conversations/: 모든 생성 미디어, 대화마다 폴더 하나
    • images/와 videos/: 표준 모드의 즐겨찾기 다운로드
    • projects/: 프로젝트별 모드의 즐겨찾기 다운로드
    • tags/: 태그 다운로드, 태그마다 폴더 하나
    • stream/: 스트림 캡처(PRO)

    각 경로는 ⚙️ 설정에서 바꿀 수 있습니다. 경로는 Chrome 다운로드 폴더를 기준으로 한 상대 경로입니다.

  8. 8

    새 작업이 생길 때마다 다시 실행하기

    소스마다 다운로드 기록이 따로 있으므로, 다음 목록 생성에서는 새 항목만 표시되고 같은 파일을 두 번 받지 않습니다. 라이브러리 전체를 보관해도 즐겨찾기가 이미 다운로드됨으로 표시되지 않으며, 그 반대도 마찬가지입니다. 파일을 삭제해서 다시 받고 싶다면 아래의 "파일을 잃어버렸는데…" 항목을 참고하세요.

폴더와 파일명이 정해지는 방식

라이브러리 전체 아카이브는 1년 뒤에도 원하는 것을 찾을 수 있어야 쓸모가 있습니다.

전체 라이브러리 스캔

즐겨찾기 일부가 아니라 전체 에셋 목록을 읽습니다. 저장하는 것을 잊었다는 이유로 생성한 작품이 빠지지 않습니다.

대화별 폴더

대화 하나에 폴더 하나. 원본 이미지와 그 이미지로 생성한 모든 동영상이 한 폴더에 뒤섞이지 않고 함께 모입니다.

실제 프롬프트 파일명

이미지는 자체 생성 프롬프트를 사용하고, 동영상은 자체 애니메이션 프롬프트를 사용하며 없을 때만 원본 이미지의 프롬프트를 빌려옵니다.

독립된 기록

전체 라이브러리 다운로드는 자체 중복 제거 기록을 유지합니다. 전체를 보관해도 즐겨찾기가 이미 다운로드됨으로 표시되지 않습니다.

각 대화 폴더의 이름은 yyyymmdd_prompt_shortID 형식입니다. 대화에 제목이 없으면 확장 프로그램은 폴더를 "untitled"로 두지 않고 그 대화의 프롬프트를 사용합니다.

폴더 안 파일의 이름은 ⚙️ 설정을 열어 📝 파일명 형식에서 고릅니다. Grok 기본은 grok_image_YYYYMMDD_id.jpg, 프롬프트 사용은 img_YYYYMMDDHHmmss_prompt.jpg 형태가 되며, 커스텀 템플릿에서는 {date} {time} {datetime} {id} {shortid} {prompt} {quality} 토큰을 자유롭게 조합할 수 있습니다. 📋 메타데이터 저장을 켜면 각 이미지와 동영상 옆에 프롬프트, 해상도 등의 정보가 담긴 .json 파일이 함께 저장됩니다. 이 기능은 모두 무료입니다.

Grok은 2026년 9월부터 미디어 목록에 프롬프트를 보내지 않습니다. v2.5.6부터 확장 프로그램은 각 항목을 생성한 대화에서 프롬프트를 되찾아 영구 캐시에 보관하므로, 이후 전체 라이브러리를 다시 생성할 때는 몇 분이 아니라 몇 초면 끝납니다. 프롬프트는 파일명이나 메타데이터 설정이 실제로 사용할 때만 가져옵니다. 직접 업로드했거나 생성 정보가 없는 에셋은 서버에 프롬프트나 대화가 없으므로 에셋 ID로 정리됩니다. 자세한 내용은 Grok Imagine 동영상을 프롬프트와 함께 저장하기를 참고하세요.

대규모 라이브러리

전체 라이브러리 스캔은 가지고 있는 에셋을 모두 읽어야 합니다. 규모가 큰 계정에서도 스캔이 끊기지 않도록 돕는 장치는 다음과 같습니다.

적응형 스로틀링과 429 백오프

목록 생성 중 Grok이 HTTP 429나 5xx 서버 오류로 응답하면 해당 요청을 다시 시도하고 스캔 속도를 자동으로 늦춥니다. 8,000개 이상의 에셋을 가진 라이브러리도 중간에 끊기지 않고 끝까지 스캔할 수 있습니다.

동시 화질 확인

동영상 화질을 제한된 동시 처리와 실시간 카운터로 확인해, 예전에 몇 분 걸리던 단계를 약 1분으로 줄였습니다.

대화 제목 일괄 조회

실제로 필요한 대화의 제목만 묶어서 가져옵니다. 전체 대화 목록을 페이지마다 훑지 않습니다.

조기 중단 날짜 필터(PRO)

스캔은 최신순으로 진행되고 지정한 날짜 범위를 지나는 즉시 멈추므로, 범위를 좁게 잡으면 라이브러리 전체를 훑지 않습니다.

다운로드는 항상 Grok에 있는 각 동영상의 가장 높은 화질을 가져옵니다. PRO 기능인 HD 업그레이드는 그 전에 Grok에 더 높은 화질의 버전을 만들어 달라고 요청합니다.

직접 선택해야 켜지며, 예상치 못한 과금 없음

1080p 업그레이드에는 SuperGrok Heavy가 필요하므로 "HD/720p를 1080p로 업그레이드" 체크박스는 기본적으로 꺼져 있습니다. 꺼 둔 상태에서는 확장 프로그램이 1080p 요청을 전혀 보내지 않고 SD에서 HD로의 업그레이드만 수행합니다. 그래도 확인 대화상자는 몇 개의 동영상이 1080p로 갈 수 있는지 알려 주므로, 해당 동영상이 조용히 목록에서 사라지는 일은 없습니다. 계정에 권한이 없는 것으로 확인되면 확장 프로그램은 한 번 감지한 시점에 이후의 1080p 요청을 멈추고 헛돌지 않습니다.

결과가 일정하게 수렴하는 업그레이드 스캔

Grok은 갓 생성된 동영상의 HD 미디어 URL을 일관되지 않게 반환했고, 그래서 같은 동영상이 어떤 스캔에서는 SD로, 다음 스캔에서는 HD로 읽혔습니다. "최근 N시간 업그레이드"를 반복할 때마다 답이 달라졌던 이유입니다. v2.5부터 확장 프로그램은 각 동영상에서 확인된 가장 높은 화질을 기억하고, 불완전한 조회 결과로 등급을 낮추지 않습니다. 기록은 30일 뒤 만료되고 개수 상한이 있으며, 기억한 URL이 유효하지 않으면 스스로 삭제됩니다. 속도 제한 때문에 전혀 확인하지 못한 동영상은 SD로 오인하지 않고 제외한 뒤 따로 보고합니다.

즐겨찾기뿐 아니라 라이브러리 전체를 업그레이드

HD 업그레이드에는 즐겨찾기 또는 🌐 전체 라이브러리 중에서 고르는 별도의 업그레이드 소스 선택기가 있어, 저장해 둔 동영상만 업그레이드할 수 있다는 제약이 없습니다. 확인 대화상자는 라이브러리를 SD, HD/720p, 1080p로 나눠 보여 주고 이번 실행에서 몇 개를 업그레이드할지 알려 줍니다. 동영상 하나당 약 8초가 걸립니다. 전체 라이브러리 스캔은 도중에 멈출 수 있습니다. 업그레이드가 끝나면 목록 생성과 다운로드 시작을 다시 실행해 더 높은 화질의 버전을 받으세요. 전체 과정은 Grok 동영상을 HD로 다운로드하기에서 확인할 수 있습니다.

문제 해결

가장 자주 문의되는 문제와 실제로 효과가 있었던 해결 방법입니다. 대부분은 설정이 잘못된 것이 아니라 Grok의 2026년 변경에서 비롯됩니다.

목록 생성과 다운로드 시작 버튼이 회색으로 비활성화되어 있습니다
먼저 현재 탭이 grok.com 페이지인지 확인하세요. 다른 사이트에서는 팝업이 두 버튼을 모두 비활성화하고 Grok 라이브러리로 이동 → 링크를 보여 줍니다. grok.com에 있는데도 버튼이 회색이라면 확장 프로그램 버전이 2.6.3보다 낮은 것입니다. 2026년 11월 12~13일에 Grok이 Imagine을 Grok 메인 앱에 통합하면서 이전 버전은 페이지를 더 이상 인식하지 못하게 되었습니다. Chrome은 몇 시간 안에 확장 프로그램을 자동으로 업데이트합니다. 지금 바로 업데이트하려면 chrome://extensions를 열고 개발자 모드를 켠 뒤 업데이트를 클릭하세요. 자세한 안내: Grok 업데이트 후 다운로드 버튼이 사라지거나 눌리지 않을 때 해결 방법.
목록 생성에서 아무것도 찾지 못하거나 최신 이미지가 빠집니다
다운로드 소스 선택기를 확인하세요. 아직 즐겨찾기로 되어 있다면 모든 생성 미디어(대화별)로 바꾸세요. Grok의 2026년 7월 변경 이후 새로 생성한 미디어는 더 이상 즐겨찾기에 추가되지 않으므로, 즐겨찾기 스캔 결과가 비어 있는 것은 정상일 수 있습니다. 전체 라이브러리 소스는 모두에게 무료이며(최근 7일간의 이미지, PRO는 동영상과 전체 라이브러리까지) v2.5.1부터 기본값입니다. 그런 다음 목록 생성을 다시 클릭하세요. 자세한 배경은 Grok 즐겨찾기가 안 보이나요? 라이브러리를 백업하는 방법 가이드에서 확인할 수 있습니다.
이미지만 다운로드되고 동영상은 받아지지 않습니다
무료 버전은 원래 이미지만 다운로드합니다. 🎬 미디어 유형 섹션에 비디오 (Pro)로 표시되는 동영상 다운로드에는 PRO 라이선스가 필요합니다. 팝업의 라이선스 섹션에서 PRO를 활성화한 뒤 비디오에 체크하고, 목록 생성을 다시 실행한 다음 다운로드 시작을 클릭하세요. 이미 받은 이미지는 다운로드 기록 덕분에 건너뜁니다. 자세한 내용은 가격 페이지를 확인하세요.
다운로드가 저절로 멈췄습니다
오류가 아니라 미리 정해진 일시정지입니다. 확장 프로그램은 동영상을 250개 받을 때마다 멈추고, 기본 3분을 기다린 뒤 자동으로 다시 진행합니다. 한 번에 받을 동영상이 250개를 넘으면 다운로드 요약에서 미리 알려 줍니다. 대기 시간은 ⚙️ 설정의 ⏱️ 속도 제한 대기에서 1~60분으로 바꿀 수 있습니다. 아무것도 클릭할 필요가 없습니다. 브라우저와 grok.com 탭만 열어 두세요.
파일 수천 개를 받은 뒤부터 다운로드가 실패합니다
아주 오래 실행하면 Grok이 도중에 다운로드를 거부하기 시작할 수 있습니다. 예를 들어 동영상 수천 개를 받은 뒤 HTTP 403 오류가 나는 경우입니다. grok.com 탭을 새로 고치고 팝업을 연 다음 다시 시작을 클릭하세요. 다운로드 기록이 이미 저장된 파일을 모두 건너뛰므로 빠진 파일만 받습니다.
HD 업그레이드가 모든 동영상이 이미 업그레이드됐다고 합니다
목록이 비어 있는 경우와 원인이 같습니다. 업그레이드 스캔은 선택한 소스의 목록을 읽는데, 즐겨찾기 목록은 불완전합니다. 업그레이드 소스를 🌐 전체 라이브러리로 설정하고 목록을 다시 생성한 뒤 업그레이드 스캔을 다시 실행하세요. v2.5부터 스캔 결과가 수렴하므로 반복 실행해도 같은 결과가 나오며, 1080p를 별도 단계로 추적하기 때문에 720p 파일을 최상위 화질로 오인하지 않습니다. HD 업그레이드는 PRO 기능입니다.
파일명, 폴더 이름 또는 metadata.json에 프롬프트가 없습니다
Grok은 2026년 9월부터 미디어 목록에 프롬프트를 보내지 않습니다. 각 항목을 생성한 대화에서 프롬프트를 되찾아오는 v2.5.6 이상으로 업데이트한 다음 목록을 한 번 다시 생성하세요. 이름은 목록 생성 단계에서 정해지므로, 이전 버전으로 만든 목록은 예전 이름을 그대로 유지합니다. 파일명에 프롬프트를 넣고 싶다면 설정에서 "프롬프트 사용" 파일명 모드를 선택하세요. 되찾은 프롬프트는 영구 캐시에 저장되므로 이후 재생성은 몇 초면 끝납니다.
Grok에서 만든 태그가 보이지 않거나, 태그에서 파일이 하나만 다운로드됩니다
Grok은 2026년 8월 마이그레이션 이후 두 가지 태그 시스템을 함께 운영하고 있으며, 각 시스템에는 다른 쪽에 있는 항목이 빠져 있습니다. 버전 2.5.2~2.5.4는 새 시스템만 읽었습니다. v2.5.6 이상으로 업데이트하세요. 두 시스템을 모두 읽어 병합하므로 태그 목록과 태그 내용이 둘의 합집합이 됩니다. 업데이트 후 해당 태그의 목록을 다시 생성하세요.
파일을 잃어버렸는데 확장 프로그램은 모두 이미 다운로드됐다고 합니다
다운로드 기록은 소스별로 따로 유지됩니다. 전체 라이브러리 소스라면 팝업을 열고 🧹 초기화를 펼친 뒤 대화 기록 지우기를 클릭하고 확인 대화상자에서 확인하세요. "다운로드 기록 초기화" 버튼은 즐겨찾기 소스에만 적용되며, 태그 소스에는 별도의 "태그 기록 삭제" 버튼이 있습니다. 기록을 지워도 Grok이나 디스크에서는 아무것도 삭제되지 않으며, 다음 실행 때 해당 항목을 다시 다운로드할 수 있게 될 뿐입니다.

그래도 해결되지 않나요? FAQ에서 더 많은 사례를 다루고 있으며, 푸터의 고객 지원 문의 버튼으로 담당자에게 직접 연락할 수 있습니다.

자주 묻는 질문

Grok Imagine 라이브러리 전체 다운로드에 관하여

Grok Imagine 즐겨찾기를 한 번에 모두 다운로드할 수 있나요?

네. grok.com/library를 열고 Grok Media Downloader 아이콘을 클릭한 뒤 다운로드 소스로 🌟 즐겨찾기를 고르고, 1. 목록 생성과 2. 다운로드 시작을 차례로 클릭하세요. 다만 2026년 7월부터 많은 계정에서 Grok의 저장됨 목록에 새 미디어가 추가되지 않으므로, 대부분은 📦 모든 생성 미디어(대화별)를 쓰는 편이 더 빠짐없는 결과를 얻습니다. 이 소스는 저장 여부와 관계없이 라이브러리 전체를 다운로드합니다. 무료 버전은 이미지를 다운로드하며, 전체 라이브러리 소스에서는 최근 7일이 대상입니다. PRO는 동영상을 추가하고 기간 제한을 없앱니다.

전체 라이브러리 다운로드란 무엇인가요?

전체 라이브러리 다운로드는 GrokMediaDownloader v2.5에서 추가된 다운로드 소스로, Grok Imagine 라이브러리에 있는 모든 생성 이미지와 동영상을 가져옵니다. 즐겨찾기로 저장했거나 태그로 분류한 항목에만 국한되지 않습니다. 확장 프로그램 팝업에서는 기존의 즐겨찾기, 태그와 나란히 다운로드 소스 선택기에 "모든 생성 미디어(대화별)"로 표시됩니다. 선별된 일부가 아니라 전체 에셋 목록을 읽기 때문에, 지금까지 생성한 모든 것을 로컬에 빠짐없이 보관하고 싶을 때 알맞은 선택입니다. 파일은 대화당 하나의 폴더로 묶이므로, 스레드를 시작한 이미지와 그로부터 생성된 동영상이 한 다운로드 폴더에 뒤섞이지 않고 한곳에 모입니다.

전체 라이브러리 다운로드는 즐겨찾기·태그 다운로드와 어떻게 다른가요?

세 가지 소스는 각기 다른 필요에 대응하며 서로 완전히 독립적입니다. 즐겨찾기는 Grok에서 저장한 항목만 다운로드하므로 대상이 작고 선별된 상태로 유지됩니다. 태그는 특정 Grok 태그나 폴더에 분류된 모든 것을 다운로드하고 tags/{tagName}/ 아래에 정리합니다. 전체 라이브러리는 두 필터를 모두 거치지 않고 생성 라이브러리 전체를 대상으로 하며, 대신 대화별로 출력을 정리합니다. 각 소스는 자체 다운로드 기록을 따로 유지하므로, 전체 라이브러리를 다운로드해도 즐겨찾기가 이미 다운로드됨으로 표시되지 않으며 그 반대도 마찬가지입니다. 세 가지를 오랫동안 함께 사용해도 한쪽이 다른 쪽의 중복 제거 기록에 영향을 주지 않습니다. v2.5 이전에는 이 부분이 흔한 혼란의 원인이었습니다.

무료 버전에서도 동영상을 다운로드할 수 있나요?

아니요. 무료 버전은 모든 소스에서 이미지를 다운로드하며, 전체 라이브러리 소스에서는 최근 7일이 대상입니다. 동영상 다운로드, 기간 제한 없는 전체 라이브러리, 날짜 필터는 $4.99 일회성 구매인 PRO에 포함됩니다. 목록 생성, 세 가지 소스, 파일명 템플릿, .json 메타데이터 파일, 다운로드 기록은 무료입니다.

확장 프로그램은 파일을 어디에 저장하나요?

Chrome 다운로드 폴더 안의 grok_downloads에 저장합니다. 전체 라이브러리 소스는 grok_downloads/conversations에 대화마다 폴더를 하나씩 만들어 저장하고, 즐겨찾기 다운로드는 images와 videos(프로젝트별 모드에서는 projects)에, 태그 다운로드는 tags에 저장합니다. 모든 경로는 설정에서 바꿀 수 있습니다. 모든 처리는 브라우저 안에서 로컬로 이루어지며, 파일은 Grok에서 디스크로 바로 저장됩니다.

폴더와 파일 이름은 어떻게 정해지나요?

각 대화가 하나의 폴더가 되며 yyyymmdd_prompt_shortID 패턴으로 이름이 지정됩니다. 대화에 제목이 없으면 확장 프로그램은 폴더를 "untitled"로 두지 않고 해당 대화의 프롬프트를 사용하므로, 몇 달 뒤에 다시 열어봐도 폴더 이름만으로 내용을 알 수 있습니다. 9월부터 Grok이 미디어 목록에 프롬프트를 보내지 않기 때문에, v2.5.6부터는 해당 항목을 생성한 대화에서 프롬프트를 되찾아옵니다. 동영상은 자체 애니메이션 프롬프트를 사용하고, 없을 때만 원본 이미지의 프롬프트를 빌려옵니다. 되찾은 프롬프트는 영구 캐시에 저장되므로 전체 라이브러리 목록 재생성이 몇 분에서 몇 초로 줄어듭니다. 프롬프트는 파일명이나 메타데이터 설정이 실제로 사용할 때만 가져오며, 이 설정을 바꾸면 팝업이 목록을 다시 생성하라고 안내합니다. 기계적인 이름을 선호한다면 "Grok 기본" 파일명 모드가 grok_image_YYYYMMDD_id 형식의 이름을 만듭니다. metadata.json에는 userId도 기록되며, 동영상 파일명도 같은 짧은 ID 접미사가 붙어 생성된 목록과 일치합니다.

새로 생성한 Grok 미디어를 확장 프로그램이 왜 찾지 못하게 되었나요?

2026년 7월 Grok은 새로운 "대화 + 에셋" 미디어 백엔드로 전환했습니다. 이전 확장 프로그램 버전이 의존하던 엔드포인트는 더 이상 저장됨 및 미디어 라이브러리 화면에 쓰이지 않으므로, v2.5.0 이전 버전은 전환 이후 생성된 이미지와 동영상을 볼 수 없습니다. GrokMediaDownloader v2.5.0은 새 백엔드에 맞춘 전면 대응으로, 새로 생성된 미디어를 다시 감지할 수 있게 합니다. 업데이트 후 chrome://extensions를 열어 확장 프로그램을 다시 로드하고 Grok 탭을 새로 고치세요. 다운로드 목록도 한 번 다시 생성해야 합니다. 그래야 병합된 태그 결과와 v2.5.6이 생성 대화에서 되찾아온 프롬프트가 반영됩니다. 프롬프트 사용 파일명과 대화 폴더 규칙은 목록 생성 단계에서 기록되며, 이전 버전으로 만든 목록에는 소급 적용되지 않습니다.

전체 라이브러리 다운로드를 날짜로 필터링할 수 있나요?

네, PRO에서 가능합니다. 전체 라이브러리 소스는 즐겨찾기 소스와 같은 날짜 필터를 지원하며, 최근 N시간 범위와 직접 지정한 날짜 범위를 모두 사용할 수 있습니다(태그 소스에는 날짜 필터가 없습니다). 스캔은 최신순으로 라이브러리를 따라가다가 선택한 범위의 끝을 지나면 바로 멈춥니다. 따라서 날짜로 필터링할 때 결과를 보기 위해 라이브러리 전체를 다 훑을 필요가 없습니다. 이는 대규모 계정에서 특히 중요합니다. 적응형 스로틀링 및 429 속도 제한 백오프와 함께 동작해 8,000개 이상의 에셋을 가진 라이브러리도 끝까지 스캔할 수 있지만, 좁은 날짜 범위는 훨씬 빨리 끝납니다. 목록 생성 버튼은 스캔, 동영상 화질 확인, 폴더 준비의 각 단계별 진행 상황을 보여 주므로 지금 어느 단계가 실행 중인지 알 수 있습니다. PRO가 없으면 전체 라이브러리 소스는 최근 7일이 대상입니다.

v2.5의 1080p 지원으로 무엇이 달라졌나요?

v2.5는 확장 프로그램 전반에서 1080p를 독립된 화질 단계로 인식합니다. 다운로드는 사용 가능한 가장 높은 화질을 자동으로 선택하며, 1080p를 HD보다, HD를 원본 파일보다 우선합니다. 스캔 통계는 모든 것을 SD와 HD로 뭉뚱그리지 않고 SD, HD/720p, 1080p에 각각 몇 개의 동영상이 있는지 구분해 보여 줍니다. HD 업그레이드 기능(PRO)은 한 번에 한 단계씩, SD에서 HD로, 720p 또는 HD에서 1080p로 끌어올릴 수 있습니다. 1080p 업그레이드에는 유료 Grok 플랜, 구체적으로 SuperGrok Heavy가 필요하므로 기본적으로 꺼져 있는 체크박스를 직접 켜야만 실행됩니다. 체크하지 않으면 확장 프로그램은 1080p 요청을 전혀 보내지 않습니다.

이전에는 업그레이드 스캔을 반복할 때마다 결과가 달랐던 이유는 무엇인가요?

Grok 서버는 갓 생성된 동영상의 HD 미디어 URL을 일관되지 않게 반환합니다. 같은 동영상을 몇 초 안에 두 번 조회하면 한 번은 해당 필드가 오고 다음에는 빠질 수 있었습니다. 해상도 필드 자체는 그대로인데도 말이죠. 그래서 같은 동영상이 어떤 스캔에서는 SD, 다음에는 HD로 보였고, "최근 N시간 업그레이드"를 반복할 때마다 다른 결과가 나왔습니다. v2.5는 업그레이드 판단 전용 화질 기록을 추가해 각 동영상에서 확인된 가장 높은 화질을 기억하고, 이후 조회가 불완전하게 돌아와도 등급을 낮추지 않습니다. 기록은 30일 뒤 만료되고 개수 상한이 있으며, 기억한 URL이 유효하지 않은 것으로 밝혀지면 자동으로 삭제됩니다.

무료 버전에서도 전체 라이브러리 다운로드를 쓸 수 있나요?

네, 최근 7일간의 이미지라면 가능합니다. v2.5.1부터 다운로드 소스 선택기는 모두에게 무료로 열려 있습니다. 자기 미디어를 볼 수 없는 소스에 묶여 있어야 할 이유가 없기 때문입니다. 무료 사용자도 "📦 모든 생성 미디어(대화별)"를 선택해 최근 7일간의 이미지를 다운로드할 수 있습니다. 확장 프로그램은 결과를 조용히 잘라내지 않고 이 범위를 처음부터 안내합니다. GrokMediaDownloader PRO는 $4.99 일회성 구매로 받는 평생 라이선스로, 동영상 다운로드를 추가하고 기간 제한을 없애 전체 라이브러리를 보관할 수 있게 하며, 날짜 필터(지정 범위 또는 최근 N시간)를 사용할 수 있게 합니다. PRO에는 스트림 캡처, 스토리 모드 내보내기, 무제한 동영상 생성 대기열, 프로젝트 다운로드, HD 및 1080p 업그레이드, 다운로드 기록 내보내기·가져오기도 포함됩니다. 모든 처리는 브라우저 안에서 로컬로 이루어지고 파일은 Grok에서 디스크로 바로 저장되며, 외부와의 연결은 Kario Studio 라이선스 서버와의 라이선스 확인뿐입니다.

다시 실행하면 같은 파일을 두 번 다운로드하나요?

아니요. 모든 소스에는 다운로드 기록이 있고, 목록 생성은 이미 기록된 항목을 제외하므로 두 번째 실행에서는 새 항목만 받습니다. 그래서 오래 걸리는 다운로드를 중간에 멈췄다가 처음부터 다시 시작하지 않고 나중에 이어서 받을 수도 있습니다. 전부 다시 받고 싶다면 먼저 해당 소스의 기록을 지우세요.

알려진 제한: 직접 업로드했거나 생성 정보가 없는 에셋은 서버에 프롬프트나 대화가 없습니다. 이런 항목은 에셋 ID로 정리됩니다.
