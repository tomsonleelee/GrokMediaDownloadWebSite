Funciones principales

Project-Based Download ofrece un flujo completo de descarga organizada

Escaneo previo a la descarga

Escanea tus favoritos de Grok antes de descargar. Consulta el total de imágenes, videos SD y videos HD con desgloses detallados.

Agrupación automática inteligente

Organiza automáticamente los archivos en carpetas de proyecto por fecha de creación y prompt de generación. Sin ordenar nada a mano.

Exportación de metadatos en JSON

Cada proyecto incluye un archivo metadata.json con los prompts de generación, marcas de tiempo y detalles de los archivos para consultarlos en el futuro.

Estadísticas de descarga

Sigue el progreso de la descarga con estadísticas en tiempo real. Consulta de un vistazo los elementos completados, fallidos y pendientes.

Cómo funciona Project Download

Cuatro pasos sencillos para organizar y descargar toda tu biblioteca de Grok

1

Escanea tus medios

Haz clic en 'Scan' para analizar tus favoritos de Grok. La extensión cuenta todas las imágenes y videos disponibles para descargar.

2

Revisa y configura

Revisa los resultados del escaneo con el número de imágenes, de videos y el tamaño estimado de la descarga. Elige qué incluir.

3

Crea el proyecto

Ponle un nombre a tu proyecto. Los archivos se organizarán automáticamente en carpetas por fecha (p. ej., 2024-03-15/) con subcarpetas según el prompt.

4

Descárgalo todo

Inicia la descarga en lote. Los archivos se guardan en carpetas de proyecto organizadas, con un metadata.json para cada grupo.

Aspectos técnicos destacados

Estructura jerárquica de carpetas

Crea carpetas anidadas: Nombre del proyecto / Fecha / Grupo de prompt, para mantener miles de archivos perfectamente organizados.

Conservación de metadatos

Cada grupo de descarga incluye un archivo JSON con el prompt original de Grok, marcas de tiempo y sumas de verificación de los archivos.

Descargas concurrentes

Usa la API de descargas de Chrome con control inteligente de concurrencia para maximizar la velocidad sin saturar el navegador.

Reanudación de descargas

Si una descarga se interrumpe, la extensión registra el progreso y puede reanudarla desde donde se quedó.

Nombres con fecha + prompt

Las carpetas se nombran con el formato {date}_{prompt}, así es fácil encontrar cualquier proyecto por la fecha en que se creó o por lo que contiene.

Origen y videos agrupados

Las imágenes de origen y todas las variaciones de video generadas (SD, HD) están en la misma carpeta, para que siempre sepas qué imagen produjo qué videos.

Incluye metadata.json

Cada carpeta de proyecto incluye un archivo JSON con todos los datos de la API de Grok: prompts originales, marcas de tiempo de generación, sumas de verificación de archivos, userId y parámetros del modelo.

Compatibilidad con texto a video

Los proyectos generados a partir de prompts de texto (sin imagen de origen) se gestionan sin problemas: la carpeta contiene solo los archivos de video y los metadatos.

Preguntas frecuentes

Todo lo que necesitas saber sobre Project Download

¿Qué es Project Download?

Project Download es una función PRO que te permite descargar todos los medios de un proyecto completo de Grok en una sola operación. Un "proyecto" de Grok es un conjunto de conversaciones, imágenes generadas y videos relacionados, agrupados en un único proyecto dentro de tu espacio de trabajo de Grok. En lugar de descargar los elementos uno por uno, Project Download lo obtiene todo de una vez y lo organiza localmente.

¿Qué contenido incluye una descarga de proyecto?

Una descarga de proyecto incluye todas las imágenes y videos generados dentro de ese proyecto. Los archivos se organizan por conversación o lote de generación, de modo que la estructura de tu proyecto de Grok se refleja en la carpeta descargada.

¿Cómo inicio una descarga de proyecto?

Ve a la página de tu proyecto de Grok, abre la extensión GrokMediaDownloader y haz clic en "Download Project". La extensión escanea el proyecto en busca de todos los medios, te muestra un resumen y empieza a descargar en cuanto confirmas.

¿Project Download conserva los nombres de archivo originales?

Sí. Project Download conserva los nombres de archivo originales asignados por Grok siempre que están disponibles. Cuando no lo están, los archivos se nombran de forma sistemática con el nombre del proyecto, la fecha de generación y un índice secuencial, para que cada archivo se pueda identificar de forma única.

¿Qué pasa si se interrumpe una descarga?

Project Download registra el progreso localmente. Si una descarga se interrumpe, por un error de red o por cerrar el navegador, puedes reanudarla volviendo a abrir la extensión en la misma página del proyecto. Los archivos ya descargados se omiten, así que solo se obtienen los que faltan.

¿Puedo descargar varios proyectos de Grok a la vez?

Por ahora, Project Download procesa un proyecto a la vez. Puedes iniciar la descarga de un proyecto, luego cambiar a la página de otro proyecto e iniciar otra descarga. Cada descarga se ejecuta de forma independiente y no bloquea a la otra.
