常見操作

如何一次下載所有 Grok Imagine 收藏？
開啟 grok.com/library，點 Grok Media Downloader 圖示並選擇下載來源：只要收藏的項目就選「🌟 收藏」，要整個媒體庫就選「📦 所有生成媒體（依對話）」。接著按「1. 生成下載列表」與「2. 開始下載」。自 Grok 2026 年 7 月的變更後，Saved 清單可能缺少新生成的媒體，所以整庫來源通常能抓得更完整。免費版下載圖片，整庫來源涵蓋最近 7 天；PRO 加上影片與完整媒體庫。逐步教學：如何一次下載所有 Grok Imagine 收藏。
Grok 收藏載入不出來或缺少新作品，該怎麼備份媒體庫？
Grok 在 2026 年 7 月更換媒體後端之後，許多帳號的收藏清單（Grok 的 Saved 頁面）不會再收到新生成的媒體，所以新作品可能不在那裡。要備份全部作品，請把下載來源選為「📦 所有生成媒體（依對話）」：它讀取的是整個媒體庫，而不是 Saved 清單。接著執行「1. 生成下載列表」與「2. 開始下載」。教學：Grok 收藏不顯示？備份您的媒體庫。
更新後下載按鈕變灰或不見了，該怎麼辦？
2026 年 11 月 12 至 13 日，Grok 把 Imagine 併入 Grok 主程式，2.6.3 之前的擴充功能版本因此讓「生成下載列表」與「開始下載」變成灰色。請更新到 2.6.3 或更新版本，並在 grok.com/library 或其他任何 grok.com 頁面使用。Chrome 會在幾小時內自動更新擴充功能；想立即更新，請開啟 chrome://extensions，開啟「開發人員模式」後按「更新」。如果彈出視窗提示您先開啟 grok.com（Library 或 Imagine 的已儲存頁面），代表目前的分頁不是 grok.com 頁面。教學：Grok 更新後下載按鈕不見了。
如何下載 Grok Imagine 影片並保留提示詞？
在彈出視窗開啟「⚙️ 設定」，檔名格式選「使用提示詞」（img_YYYYMMDDHHmmss_prompt.jpg），或用含 {prompt} 標記的「自訂模板」。若要連同解析度等資訊保留完整提示詞，請開啟「📋 儲存 Metadata」，每張圖片與每支影片旁都會多一個 .json 檔。然後重新產生清單，讓擴充功能抓取提示詞。這些選項都是免費的；下載影片則需要 PRO。教學：下載 Grok Imagine 影片並保留提示詞。
如何下載 HD 高畫質的 Grok 影片？
下載時一律取用 Grok 該影片現有的最高畫質。想讓更多影片變成 HD，請使用 HD 畫質升級（PRO）：它會掃描收藏或整個媒體庫，列出 SD、HD/720p、1080p 各有幾支，並請 Grok 將影片升級到 720p，每支約 8 秒。1080p 需另外勾選，而且您的 Grok 帳號必須訂閱 SuperGrok Heavy。升級完成後，再執行一次生成下載列表與開始下載，就能抓到升級後的檔案。教學：下載 HD 高畫質的 Grok 影片。
免費版可以下載影片嗎？
不行。免費版在三種來源都只下載圖片，整庫來源涵蓋最近 7 天。下載影片、完整媒體庫、日期篩選與 HD 畫質升級屬於 PRO，一次性 $4.99 買斷。生成下載列表、檔名模板、.json metadata 檔與下載紀錄都是免費的。請參考價格方案。

基本功能

為什麼擴充功能抓不到新產生的 Grok 媒體？
2026 年 7 月起，Grok 改用全新的「對話 + 資產」媒體後端。舊版擴充功能所依賴的端點已不再支撐 Saved 與媒體庫畫面，因此 v2.5.0 之前的任何版本都看不到該次遷移之後產生的圖片與影片。GrokMediaDownloader v2.5.0 是針對新後端的完整適配，恢復了對新生成媒體的偵測能力。修正方式：從 Chrome 線上應用程式商店安裝最新版本，開啟 chrome://extensions 重新載入擴充功能，再重新整理 Grok 分頁。最後請重新產生一次下載清單：提示詞檔名與新的對話資料夾規則是在「生成下載列表」階段寫入的，不會回溯套用到舊版本建立的清單上。也正是這次後端遷移，才讓全新的整庫下載來源得以實現。
1080p 升級需要什麼條件？
將影片升級到 1080p 需要付費的 Grok 方案，具體來說是 SuperGrok Heavy。由於會消耗付費額度，GrokMediaDownloader 把它放在一個名為「將 HD/720p 升級至 1080p」的選項後面，預設為關閉，必須明確勾選才會執行。未勾選時，擴充功能完全不會送出任何 1080p 請求，只執行 SD 到 HD 的升級，因此絕不會有意外扣費的情況。確認對話框仍會回報有多少支影片可以升級到 1080p，這些項目不會被默默略過而看不見。若您的帳號實際上沒有該權限，擴充功能偵測到一次後就會立即停止後續所有 1080p 請求，不會反覆失敗空轉。SD 到 HD 的升級不需要 SuperGrok Heavy。HD 畫質升級本身是擴充功能的 PRO 功能。
更新到 v2.5.6 之後應該先做什麼？
三個步驟。第一，開啟 chrome://extensions 重新載入 GrokMediaDownloader，並重新整理所有已開啟的 Grok 分頁，讓新的內容腳本生效。第二，重新產生一次下載清單。提示詞檔名與新的對話資料夾命名是在「生成下載列表」階段寫入的，v2.5.6 也是在這個階段從生成該媒體的對話取回提示詞，因此舊版本產生的清單不會自動套用新規則。新的提示詞快取會保留取回的結果，之後整庫重新產生清單只需數秒，而非數分鐘。第三，若您想要有意義的檔名，請開啟設定並選擇「使用提示詞」檔名模式；若選擇「Grok 原生」，輸出的檔名會是 grok_image_YYYYMMDD_id 這種形式。提示詞只會在檔名格式或 metadata 設定真的用到時才擷取；變更這些設定之後，彈出視窗會提示您重新生成列表。另有一項已知限制需要留意：由您自行上傳、或沒有生成資訊的資產，伺服器端本身即無提示詞與對話歸屬，這類項目會以資產 ID 命名，而非以提示詞命名的資料夾。
檔案遺失了 —— 要怎麼重新下載已被記錄為「已下載」的媒體？
v2.5 為每個下載來源保留各自獨立的下載紀錄，因此該按哪個重置按鈕，取決於您當初用的是哪個來源。標示為「重置下載歷史（將重新下載所有檔案）」的按鈕只作用於「收藏」來源。若您當初是用「📦 所有生成媒體（依對話）」下載，請開啟擴充功能彈出視窗，展開「🧹 清除操作」區塊，點擊「清除對話歷史」。在出現「確定清除所有對話下載歷史？此操作無法復原。」的確認對話框時選擇確定，接著應會看到「對話下載歷史已清除」。此操作會清除「所有生成媒體（依對話）」來源的下載紀錄，以及影片畫質判定的快取；不會動到您電腦上已儲存的檔案，也不會影響「收藏」或「標籤」的紀錄。完成後請重新選擇「所有生成媒體（依對話）」並再次執行「生成下載列表」，所有項目都會被視為尚未下載，即可完整重新下載。「標籤」來源則有自己的「清除標籤歷史」按鈕。
生成下載列表找不到東西，或 HD 升級說全部都已升級 —— 是哪裡有問題？
您的下載來源很可能仍設定為「收藏」。Grok 在 2026 年 7 月的後端變更之後，新生成的媒體不會再自動加入收藏：以實際帳號實測，媒體庫最新的 30 個項目中有 11 個完全不在完整的收藏清單裡，而 Grok 官方的 Saved 頁面也已完全停止呼叫那支端點。因此掃描「收藏」來源可能真的回傳空的、或漏掉您最新的作品；而 HD 升級掃描讀的是同一份殘缺清單，於是回報「所有影片都已升級」。自 v2.5.1 起，下載與升級的預設來源都已改為整庫，且來源選擇器對所有人免費開放。請將下載來源改為「📦 所有生成媒體（依對話）」、升級來源改為「🌐 整庫」，然後重新掃描。您的媒體並沒有不見 —— 只是舊來源看不到它們。
剛在 Grok 建立的標籤，在擴充功能裡看不到
請更新到 v2.5.6。Grok 已把標籤系統改建在資產模型上（collection），但 8 月的這次遷移在新舊兩個方向都沒有完成。以實際帳號唯讀實測比對，兩邊各自都有對方缺少的東西：一個 2026-08-15 建立的標籤只存在於新系統，而舊儲存區最新的一筆停在 2026-03-28；反過來，某個舊標籤在新 API 只有 2 筆，在舊 API 卻有 233 筆。v2.5.6 會同時讀取新舊兩套標籤系統並合併，因此標籤清單與標籤內容一律是兩者的聯集 —— 新建立的標籤、舊標籤的完整內容，以及只存在於舊系統的標籤，全都會出現。v2.5.2 到 v2.5.4 只讀新的 collection API，這正是某些標籤只抓到一小部分檔案、甚至只抓到一個的原因；v2.5.3 與 v2.5.4 補上了標籤清單與內容的分頁修正，以及完整掃描診斷，讓標籤數量多的帳號也能看到較舊的標籤。標籤下載支援提示詞檔名，影片會使用自己的動畫提示詞，或借用來源圖片的。更新後請重新載入擴充功能，並重新產生一次下載清單。您也可能會看到一個名為「Liked」的內建標籤 —— 那是 Grok 新建的，內容與您過去的「收藏」並不相同。
為什麼檔名、資料夾名與 metadata 裡沒有提示詞？
因為自 9 月起，Grok 不再於媒體清單中提供提示詞，所以 v2.5.6 之前的版本寫出的檔名、資料夾名與 metadata.json 都沒有提示詞。這不是設定問題 —— 任何設定組合都救不回來，因為資料根本沒有送過來。v2.5.6 改為從生成該媒體的對話取回提示詞；影片會取得自己的動畫提示詞，沒有時才借用來源圖片的。新的提示詞快取會持續保存取回的結果，因此第一次之後，整庫重新產生清單會由數分鐘降到秒級。提示詞只會在檔名格式或 metadata 設定真的用到時才擷取；變更這些設定之後，彈出視窗會提示您重新生成列表。v2.5.6 另外還為 metadata.json 補上 userId，影片檔名也與清單一致，帶有相同的短 ID 尾碼。更新後請在 chrome://extensions 重新載入擴充功能，並重新產生一次下載清單。已經下載完成的檔案不受影響 —— 擴充功能不會回頭替更新前寫好的檔名或 metadata 補上提示詞。
Generate List 按鈕是做什麼的？
「1. 生成下載列表」（Generate List）會依您選的下載來源建立下載清單：「🌟 收藏」、「🏷️ 標籤」或「📦 所有生成媒體（依對話）」。它透過 Grok 的媒體庫 API 讀取該來源，而不是掃描您目前開著的頁面，所以在任何 grok.com 頁面都能用，也不需要捲動頁面。已經在該來源下載紀錄裡的項目會被排除。完成後，狀態面板會依層級列出圖片，以及 SD、720p、HD、1080p 影片的總計、已下載與未下載數量，並跳出「下載摘要」對話框詢問「確定開始下載？」：按「確定」立刻開始，按「取消」則保留「2. 開始下載」稍後再按。掃描時若 Grok 回應 HTTP 429 或 5xx 錯誤，擴充功能會重試該請求並自動放慢掃描。開始下載後，擴充功能每下載 250 支影片會刻意暫停一次（預設 3 分鐘，可在「⚙️ 設定」→「⏱️ 速率限制冷卻」調整為 1 到 60 分鐘），之後自動繼續；單次下載超過 250 支影片時，下載摘要會先提醒。檔名與 metadata 選項是在建立清單時套用的，變更後請重新生成清單。所有處理都在您的瀏覽器本機完成。
什麼是日期篩選（日期區間／最近 N 小時）？
日期篩選是 PRO 功能，適合媒體庫很大的使用者。在彈出視窗的「📥 下載來源與篩選」區塊中，預設是「下載全部」；可以改選「日期區間」並設定起訖日期，或選「最近」再輸入小時數（最近 N 小時內的圖片/視頻）。之後生成下載列表只會包含該範圍內建立的媒體。日期篩選適用於收藏與所有生成媒體兩種來源，標籤來源沒有日期篩選；整庫掃描一越過範圍就會提早停止。例如設定最近 24 小時，就只抓今天生成的作品；設定一週的日期區間，適合每週固定下載一次。日期篩選會與下載紀錄搭配，已經下載過的檔案仍會被略過。沒有 PRO 時，整庫來源涵蓋最近 7 天。此功能包含在 $4.99 的 PRO 終身授權中。
Stream Capture 與 Generate List 有什麼不同？
Generate List 和 Stream Capture 在 GrokMediaDownloader 中服務於不同的工作流程。Generate List 是一個批次掃描工具，會透過 Grok 的媒體庫 API 讀取您選擇的下載來源（收藏、標籤或整個媒體庫），找出所有圖片和影片，過濾重複項目，並建立下載佇列。您可以在想要下載累積媒體時手動執行。相比之下，Stream Capture 是一個即時監控系統，使用 MutationObserver 監聽 DOM 中新出現的圖片。當您在 grok.com 上瀏覽和創作時，Stream Capture 會在新圖片出現在畫面上的瞬間自動偵測並加入佇列，每次工作階段最多可捕獲 1,000 張圖片。簡單來說，Generate List 是從媒體庫中已有的作品進行回溯式批次下載，而 Stream Capture 則是一張即時捕獲網，能在媒體產生的當下就攔截。Stream Capture 是 PRO 功能。這兩項功能都完全在客戶端運作，不會將任何資料傳送到外部伺服器。
HD Upgrade 是如何運作的？
HD Upgrade（彈出視窗中的「✨ HD 畫質升級」）是 PRO 功能，會請 Grok 為您的影片產生較高畫質的版本。先選擇「🎯 升級來源」：收藏或「🌐 整庫」，可視需要只升級最近 N 小時的影片，再按「🚀 升級畫質」。擴充功能會先掃描影片，列出 SD、HD/720p、1080p 各有幾支、這次會升級幾支，讓您在送出任何請求前先確認。接著它會請 Grok 把每支 SD 影片升級到 HD（720p），每支約 8 秒。把 HD/720p 影片升級到 1080p 是另一個需要勾選的選項「將 HD/720p 升級至 1080p」，而且您的 Grok 帳號必須訂閱 SuperGrok Heavy。已經是最高可用畫質的影片會被略過。升級完成後，請再執行一次生成下載列表與開始下載：下載時一律取用可用的最高畫質。整個過程都在您的瀏覽器中執行。逐步教學：下載 HD 高畫質的 Grok 影片。
我換了電腦，下載紀錄還在嗎？
預設情況下，GrokMediaDownloader 會將您的下載歷史儲存在當前電腦的 Chrome 本地儲存空間中。這意味著如果您更換到新電腦、格式化硬碟或重新安裝 Chrome，您的歷史紀錄不會自動轉移。然而，PRO 用戶可以使用 Export/Import Data 功能，將整個下載歷史匯出為檔案並在任何其他裝置上還原。這在升級電腦或維護多台工作站時進行跨裝置轉移非常實用。匯出功能會建立一個包含所有下載紀錄的可攜式資料檔案，而匯入流程則能無縫還原所有資料。由於 GrokMediaDownloader 是採用 Manifest V3 架構的 Chrome 擴充功能，100% 客戶端處理，不會將任何個人資料傳送到外部伺服器。您的歷史紀錄始終保持私密且在您的控制之下，僅儲存在本地 Chrome 儲存空間中。

Story Mode Helper

什麼是 Story Mode Helper？
Story Mode Helper 是 GrokMediaDownloader v2.0 推出的重要功能，設計為 Chrome 側邊面板中的完整影片工作室。它提供支援拖放排序的故事板管理器，讓您將多個影片片段排列成連貫的敘事序列。您可以從任何影片片段中擷取特定畫格，並使用「發送畫格到 Grok」功能將畫格連同自訂提示詞上傳到 Grok Imagine，生成延續您故事的續集影片。影片合併功能使用 FFmpeg.js，這是 FFmpeg 的 WebAssembly 實作，完全在您的瀏覽器中運行。這意味著所有影片處理，包括標準化、解析度匹配和最終合併，都在本地完成，不會上傳任何內容到伺服器。影片資料儲存在 IndexedDB 中以有效處理大型二進位檔案。Story Mode Helper 將 Grok AI 從簡單的圖片生成器轉變為完整的創意故事講述平台，一切都在您的瀏覽器中完成。排列片段是免費的；匯出合併後的影片需要 PRO。
如何使用 Send Frame to Grok 功能？
「發送畫格到 Grok」是 Story Mode Helper 中的工作流程功能，連接您現有的影片片段和新的 Grok AI 生成。使用方法是先在 Chrome 側邊面板中開啟 Story Mode Helper，從故事板中選擇一個影片片段來檢視其畫格。您可以透過互動式膠捲瀏覽影片並選擇任意畫格，不僅限於最後一幀。選定要從哪個畫格繼續後，輸入描述影片下一步應該發生什麼的文字提示詞。點擊「傳送畫格並生成影片」，擴充功能會自動將選定的畫格圖片連同您的提示詞上傳到 Grok Imagine。Grok 接著會生成一個從該畫格視覺上延續的新影片。生成的影片可以加回您的故事板進行進一步編輯或合併。這創造了一個無縫的迭代工作流程，完全在您的瀏覽器中建構更長的 AI 生成影片敘事。
影片合併是在本地還是雲端處理？
GrokMediaDownloader 中所有的影片合併都完全在您的瀏覽器本地執行。擴充功能使用 FFmpeg.js，這是業界標準 FFmpeg 影片處理庫的 WebAssembly（WASM）編譯版本。這意味著 FFmpeg 的完整功能直接在您的 Chrome 瀏覽器中作為客戶端程式碼運行，絕對不會將任何影片資料上傳到任何外部伺服器或雲端服務。當您在 Story Mode Helper 中合併影片時，FFmpeg.js 引擎會在您瀏覽器的記憶體中處理影片標準化、解析度調整、幀率匹配和最終串接。影片二進位資料在處理期間暫時儲存在 IndexedDB 中。這種方式確保了完全的隱私保護，因為您的創意內容永遠不會離開您的裝置。由 Kario LLC 發行的 GrokMediaDownloader 從一開始就採用零伺服器架構設計。這款在 Chrome Web Store 上有 5,000+ 位用戶、評分 4.1/5（27 則評分）的擴充功能，所有處理都在客戶端完成。
Storyboard 中的 Master 是什麼意思？
在 GrokMediaDownloader 的 Story Mode Helper 中，Master 標記會指派給故事板序列中的第一個影片片段。Master 影片作為整個合併輸出的參考標準。當您啟動合併流程時，故事板中所有其他影片片段會自動調整解析度和幀率以匹配 Master 的規格。這確保了最終合併影片中一致的視覺品質，防止不同尺寸或速度的片段之間出現突兀的轉場。例如，如果您的 Master 是 1080p、24fps 的影片，所有後續片段在合併前都會使用 FFmpeg.js 標準化到這些確切的規格。您可以透過拖放重新排列故事板來更改哪個片段是 Master。建議選擇最高品質的片段作為 Master 以獲得最佳輸出結果。整個標準化和合併過程都透過 WebAssembly 在本地執行，不涉及任何雲端處理。
影片儲存空間有限制嗎？
GrokMediaDownloader 使用 IndexedDB（瀏覽器原生資料庫）來儲存 Story Mode Helper 的影片資料。儲存容量取決於您瀏覽器的設定和可用磁碟空間。大多數現代 Chrome 安裝允許 IndexedDB 使用從數百 MB 到數 GB 的儲存空間，超過後才會提示要求額外權限。側邊面板介面會即時顯示您目前的儲存使用量，讓您可以監控故事板影片佔用了多少空間。如果您接近儲存限制，可以匯出已完成的專案並清除較舊的影片資料以釋放空間。之所以特別選擇 IndexedDB 而非其他儲存方式，是因為它能有效處理影片檔案等大型二進位資料，而不會降低瀏覽器效能。由於 GrokMediaDownloader 中所有處理都透過其 Manifest V3 架構在客戶端完成，您的影片資料永遠不會離開本地瀏覽器儲存空間。這種設計同時確保了您創意工作的效能和隱私。

v2.3 新功能

什麼是標籤式下載？
標籤式下載是 GrokMediaDownloader v2.3 推出的功能，讓您按照 Grok 的標籤（資料夾）系統來下載媒體。不需要一次下載所有收藏，您可以在下載來源選擇器中選擇「🏷️ 標籤」，再從清單中選取特定標籤來定向下載。擴充功能接著會掃描並下載該選定標籤內的所有媒體。每個標籤維護自己獨立的下載歷史，因此您可以對不同標籤重新執行下載，無需擔心跨標籤的重複問題。下載的檔案會自動整理在電腦的 grok_downloads/tags/{標籤名稱}/ 路徑下，保持每個標籤的媒體清楚分離。這對於使用 Grok 標籤系統來組織不同專案、主題或角色合集的創作者特別有用。標籤下載圖片是免費的；下載標籤中的影片需要 PRO。
什麼是自訂檔名模板？
自訂檔名模板是 GrokMediaDownloader v2.3 推出的功能，提供三種靈活的檔案命名方式。第一個選項是「Grok 原生」，保留 Grok 指定的原始檔名格式。第二個選項是「使用提示詞」，使用您的生成提示詞文字作為檔名以便識別。第三個選項是「自訂模板」，讓您使用 {date}、{datetime}、{prompt}、{quality} 等代碼建立自由格式的模板，這些代碼在下載時會動態替換。例如，{date}_{prompt}_{quality} 模板會產生像 20260409_日落風景_HD.jpg 這樣的檔名。此功能對所有用戶開放，包括免費版和 PRO 版。如果您之前使用了較早的「以提示詞作為檔名」設定，您的偏好會自動遷移到新的「使用提示詞」選項。自訂檔名模板適用於所有下載模式，包括批次下載、Stream Capture 和標籤式下載。
Story Mode 的 Frame Lock 是什麼？
Frame Lock 是 GrokMediaDownloader v2.3 推出的 Story Mode 增強功能，讓您精確控制影片延續點。當使用「發送畫格到 Grok」生成續集影片時，您現在可以透過互動式膠捲從影片片段中選擇任意畫格，而不僅是預設的最後一幀。這讓您可以選擇希望 Grok 從哪個確切的視覺時刻開始延續。在您發送畫格並且 Grok 生成續集影片後，選定的畫格會在膠捲上以橘色指示器鎖定，標記轉場點的位置。當您匯出或合併最終影片時，FFmpeg.js 會自動在鎖定畫格位置裁剪來源片段。這可以防止連續片段之間出現重疊或重複的內容，確保合併的故事板輸出中有無縫的視覺轉場。Frame Lock 消除了之前需要的手動裁剪，使迭代式影片創作工作流程對故事創作者來說顯著更加順暢。
