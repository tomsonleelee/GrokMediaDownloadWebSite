Grok download button missing after update

You opened Grok after its November update and the download buttons are gone or greyed out? If you use Grok Media Downloader, the fix is usually one extension update. This guide explains what changed on Grok's side, why versions before 2.6.3 stopped working, and how to update and start downloading again.

Short answer

On 12–13 November 2026 Grok folded Imagine into its main app, and on some accounts the /imagine pages now redirect to Library or to the home page. Grok Media Downloader versions before 2.6.3 only enabled 1. Generate List and 2. Start Download on /imagine pages, so the buttons stayed greyed out.

Update to version 2.6.3 or newer. Chrome does this automatically within a few hours. To do it now, open chrome://extensions, turn on Developer mode and click Update. Then open grok.com/library, reload the tab and use the extension as before.

Which download button this guide is about

This guide covers the buttons in the Grok Media Downloader browser extension. Grok's own interface, including any download options built into Grok itself, is outside our control and can change at any time. For those, check Grok's own help.

What changed on Grok in November 2026

On 12 and 13 November 2026 Grok folded Imagine into the main Grok app. The sidebar now shows Library, which is where your generated images and videos are listed. On some accounts the Imagine tab disappeared, and the /imagine pages, including grok.com/imagine/saved, redirect to Library or to the home page. Other accounts still have the Imagine tab, because Grok is moving accounts over one at a time. Two people can therefore see different layouts on the same day.

For an extension that was built around the Imagine pages, the redirect mattered more than the new look. The next section explains why.

Why the extension's buttons went grey

Versions of Grok Media Downloader before 2.6.3 checked the address of the active tab and only enabled their main buttons on grok.com/imagine pages. Once Grok started redirecting those pages, that check failed on every page the user could reach. The popup kept 1. Generate List and 2. Start Download greyed out and showed this message:

“Please use this extension on Grok Imagine Favorites page.”

The link under it, Go to Favorites →, opened grok.com/imagine/saved, which redirected again. Inside the old version there was no way forward, so it looked as if the download buttons had disappeared with Grok's update.

Version 2.6.3, released on 23 November 2026, removed that restriction. The extension now works on any grok.com page, and grok.com/library is the recommended one. Which Grok page is open does not change what gets downloaded, because the extension reads your library directly instead of the page in front of you.

How to fix it

The whole fix takes a few minutes. You do not need to remove the extension, and your settings, download history and PRO license stay where they are.

  1. 1

    Check your extension version

    Type chrome://extensions into the address bar and press Enter. Find Grok Media Downloader and read the version number on its card. If it shows 2.6.3 or higher, you already have the fix: go to step 4.

  2. 2

    Update the extension

    Chrome updates extensions automatically, usually within a few hours of a new release. To update right away, turn on Developer mode with the switch in the top-right corner of chrome://extensions, then click the Update button that appears at the top of the page. Chrome checks all your extensions and installs any pending updates.

  3. 3

    Confirm the new version

    Check that the card now shows 2.6.3 or newer. You can switch Developer mode off again afterwards; it is only needed for the Update button.

  4. 4

    Open grok.com/library and reload it

    Go to grok.com/library, or any other grok.com page, and reload the tab so the updated extension connects to it. Make sure you are signed in.

  5. 5

    Open the popup and check the buttons

    Click the Grok Media Downloader icon. From top to bottom, the popup shows:

    • 📊 Status: how many images and videos there are, by quality, filled in after a scan.
    • 🎬 Media Types: images, and videos with PRO.
    • 📥 Download Source & Filter: where the list comes from, plus the PRO date filter.
    • 1. Generate List: clickable again on any grok.com page.
    • 2. Start Download: becomes active once a list with files to download exists.
  6. 6

    Download as usual

    Choose a Download Source and click 1. Generate List. When the scan finishes, the 📊 Download Summary dialog asks “Start download?”: click OK to start, or click Cancel and use 2. Start Download when you are ready. Files you downloaded with the old version are skipped. If recent media is missing from the list, use 📦 All Generated Media (by Conversation) instead of 🌟 Favorite; Grok favorites not loading? Back up your library explains why. You can also get the extension from the Chrome Web Store if it is not installed on this computer yet.

The “open grok.com” message in 2.6.3 and newer

Version 2.6.3 still greys out the buttons in one situation: when the active tab is not a grok.com page, for example when you open the popup on a news site or an empty new tab. It then shows:

“Please open grok.com (Library or Imagine Saved page) and try again.”

Click Go to Grok Library → under the message, or switch to a grok.com tab, and open the popup again. The extension always works with the active tab of the current window, so if you have several windows open, click the icon in the window that shows Grok.

Troubleshooting

If the buttons are still not available after the update, one of these usually explains it.

The buttons are still greyed out after updating

Check that the active tab really is a grok.com page, then reload that tab and open the popup again. If the popup shows the “Please open grok.com” message, you are on another tab or window. If the version on chrome://extensions is still below 2.6.3, the update has not arrived yet.

Clicking Update does not install 2.6.3

Chrome sometimes needs a while to pick up a new release. Wait a few hours and click Update again. As a last resort, remove the extension and add it again from the Chrome Web Store. Removing it clears the extension's local download history, so the next run downloads files again, and PRO users should keep their license key at hand in case they need to activate it again.

Only 2. Start Download is greyed out

That is expected until a list exists. Click 1. Generate List first. If you changed the filter, or switched to filename settings that need prompts, after generating the list, the popup asks you to generate it again and Start stays greyed out until you do. Both buttons are also disabled while a scan is running.

The popup says “Generation Failed”

Make sure you are signed in on grok.com, reload the tab and try again.

I can no longer find Imagine or my saved media in Grok

On accounts that received the November change, your media is under Library in Grok's sidebar, at grok.com/library. Where Grok places its own pages is up to Grok, so if you cannot find something there, check Grok's own help.

Frequently asked questions

Why did the download buttons disappear after Grok's update?

Generate List and 2. Start Download on /imagine pages, so they stayed greyed out. Version 2.6.3 works on any grok.com page.

Which version of Grok Media Downloader fixes it, and is it free?

Version 2.6.3, released on 23 November 2026, and every newer version. The update is free for all users, on the free version and on PRO. Chrome installs it automatically, or you can force it from chrome://extensions with Developer mode and Update.

Which Grok page should I use the extension on?

grok.com/library is the recommended page. Since 2.6.3 any grok.com page works, and grok.com/imagine/saved still works on accounts that have it. Keep the Grok tab active when you click the extension icon.

My account still has the Imagine tab. Do I need to update?

Yes, it is worth it. Grok is moving accounts over one at a time, so the redirect can reach your account at any point. Version 2.6.3 works on Imagine pages and on Library alike.

Will updating delete my settings, download history or license?

No. Chrome updates the extension in place, so your settings, download history and an activated PRO license stay as they are.

Does this guide cover Grok's own download button?

No. It is about the Grok Media Downloader extension. Grok's own interface is outside our control and changes over time; for its built-in download options, check Grok's own help.
