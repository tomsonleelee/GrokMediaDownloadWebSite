核心功能

專案下載提供完整的有組織下載工作流程

下載前預掃描

「生成下載列表」會先掃描你的 Grok 收藏，顯示將下載的專案、圖片與影片（SD、HD、1080p）數量。

智慧自動分組

按建立日期和生成提示詞自動將檔案整理到專案資料夾中。無需手動排序。

中繼資料 JSON 匯出

每個專案都包含 metadata.json 檔案，記錄生成提示詞、時間戳記和檔案詳細資訊，方便日後參考。

下載統計

透過即時統計追蹤下載進度。一目了然地查看已完成、失敗和剩餘項目。

專案下載運作方式

四個步驟，把 Grok 收藏整理成專案資料夾

1

選擇模式

下載來源選「收藏」，並在「⚙️ 設定」把下載模式設為「依專案分組」。

2

生成下載列表

按「生成下載列表」。彈出視窗會顯示尚未下載的專案、圖片與影片數量，你也可以選擇是否包含圖片與影片。

3

開始下載

按「開始下載」。每張原始圖片會在 grok_downloads/projects 下有自己的資料夾，以 {date}_{prompt} 命名。

4

取得整理好的資料夾

每個資料夾裡有原始圖片、由它生成的影片與圖片，以及 metadata.json。已下載過的檔案會略過。

技術亮點

每張原始圖片一個資料夾

grok_downloads/projects/{date}_{prompt}/ 內放原始圖片、生成的影片與 metadata.json，相關檔案集中在一起。

保留中繼資料

每個專案資料夾都附上 metadata.json，記錄提示詞、建立時間與生成項目清單。

速率限制冷卻

擴充功能每下載 250 支影片會刻意暫停一次，以免超出 Grok 的限制，預設 3 分鐘（⚙️ 設定 → ⏱️ 速率限制冷卻），之後自動繼續。

略過已下載的檔案

下載歷程會記錄每個已儲存的檔案，中斷後再次執行「生成下載列表」與「開始下載」，已儲存的檔案會自動略過。

日期 + 提示詞命名

資料夾以 {日期}_{提示詞} 格式命名，讓你可以輕鬆按照建立時間或內容找到任何專案。

原始圖片 + 影片分組

原始圖片和所有生成的影片版本（SD、HD）放在同一個資料夾中，讓你永遠知道哪張圖片產生了哪些影片。

包含 metadata.json

每個專案資料夾都附上 metadata.json，記錄提示詞、建立時間、原始圖片與生成項目清單。

支援文字生成影片

從文字提示詞生成的專案（無原始圖片）也能妥善處理 — 資料夾中只包含影片檔案和元資料。

常見問題

關於 Project Download 的所有問題解答

Project Download 是什麼？

Project Download 是「收藏」來源的一種下載模式。它不把圖片和影片分到不同資料夾，而是把每張原始圖片和由它生成的影片一起存進同一個專案資料夾，並附上記錄內容的 metadata.json。由於專案資料夾以影片為核心，而影片下載需要 PRO，因此 Project Download 屬於 PRO 功能。

如何開啟 Project Download？

在彈出視窗打開「⚙️ 設定」，在「⭐ 收藏」群組把下載模式設為「依專案分組」。下載來源選「收藏」，再照常點「生成下載列表」與「開始下載」。這個設定只適用於收藏來源；標籤與所有生成媒體有各自的資料夾結構。

專案資料夾裡有什麼？

每張原始圖片在 grok_downloads/projects 下有一個資料夾，以日期與提示詞命名（例如 20260123_a_teddy_bear）。裡面有原始圖片、由它生成的影片與圖片，以及記錄提示詞、建立時間與生成項目清單的 metadata.json。沒有原始圖片的文字生成影片，資料夾裡只會有影片。

為什麼有些專案資料夾缺檔案？

先前已下載過的檔案會被略過，因為下載歷程會防止重複下載。如果想為以前用標準模式下載過的項目建立完整的專案資料夾，請先清除收藏的下載歷程；選擇「依專案分組」時，彈出視窗也會顯示這個提示。

Project Download 會包含 2026 年 7 月以後生成的媒體嗎？

只包含在 Grok 收藏中的媒體。Grok 在 2026 年 7 月更換媒體後端後，新生成的媒體不會再加入收藏，因此專案資料夾只涵蓋收藏清單中的內容。若要備份全部內容，請使用「所有生成媒體」來源，它會依對話各存成一個資料夾。

下載中斷或自己暫停時怎麼辦？

下載歷程會記錄每個已儲存的檔案，重新整理後再按「生成下載列表」與「開始下載」，已儲存的檔案會自動略過。另外，擴充功能每下載 250 支影片會刻意暫停一次，以免超出 Grok 的限制，預設 3 分鐘（⚙️ 設定 → ⏱️ 速率限制冷卻），之後自動繼續。

Project Download 是免費功能嗎？

不是。專案資料夾會把每張圖片和它生成的影片放在一起，而影片下載需要 PRO；免費版會以標準資料夾結構下載圖片。升級至 GrokMediaDownloader PRO（$4.99 一次付清、終身授權）即可解鎖影片下載與 Project Download，以及 Stream Capture、Story Mode 匯出和不限次數的 Video Gen Queue。
