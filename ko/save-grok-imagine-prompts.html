파일명에 프롬프트를 넣거나, 나만의 이름 규칙을 쓰거나, 다운로드한 파일마다 전체 프롬프트가 담긴 .json 파일을 함께 저장하세요.

2026년 11월 28일 업데이트 · 확장 프로그램 2.6.3 버전 기준

요약

GrokMediaDownloader를 설치하고 grok.com/library를 엽니다. 팝업에서 ⚙️ 설정을 열고 📝 파일명 형식에서 프롬프트 사용을 고르거나, {prompt}가 들어간 커스텀 템플릿을 지정합니다. 📋 메타데이터 저장을 켜면 파일마다 전체 프롬프트가 담긴 .json 파일도 함께 저장됩니다. 그다음 1. 목록 생성과 2. 다운로드 시작을 누르면 됩니다. 파일명과 메타데이터 옵션은 무료이며 이미지에 바로 쓸 수 있고, 동영상 다운로드에는 PRO가 필요합니다.

프롬프트를 남기는 세 가지 방법

세 가지를 함께 써도 됩니다. 모두 확장 프로그램 팝업의 설정이며, Grok에 있는 데이터는 전혀 바꾸지 않습니다.

파일명에 프롬프트 넣기

"프롬프트 사용" 형식은 img_20261128143015_a_red_fox_in_fresh_snow_1a2b3c4d.jpg처럼 이름을 붙여, 컴퓨터에서 프롬프트로 파일을 검색할 수 있습니다.

나만의 이름 규칙

"커스텀 템플릿"은 {date}, {prompt}, {shortid} 같은 토큰을 조합해 정리 방식에 맞는 이름을 만듭니다.

전체 프롬프트를 .json으로

"메타데이터 저장"은 다운로드한 파일마다 작은 .json 파일을 옆에 만들어 전체 프롬프트, 생성 시각, ID, 그리고 동영상이라면 저장된 화질까지 기록합니다.

프롬프트 저장: 무료와 PRO

파일명과 메타데이터 관련 기능은 모두 무료입니다. PRO는 동영상 다운로드와 전체 라이브러리를 더해 줍니다.

단계별 안내

  1. 1

    단계 1: 확장 프로그램을 설치하고 Grok 열기

    Chrome 웹 스토어에서 GrokMediaDownloader를 추가하고 아이콘을 툴바에 고정하세요. 같은 Chrome 프로필에서 Grok에 로그인되어 있어야 합니다.

    grok.com/library를 엽니다. 2.6.3 버전부터는 grok.com의 어느 페이지에서나 작동합니다. grok.com이 아닌 탭에서는 팝업이 먼저 Grok을 열라고 안내합니다.

  2. 2

    단계 2: 파일명 형식 고르기

    확장 프로그램 아이콘을 눌러 팝업을 열고 ⚙️ 설정을 펼칩니다. PRO 사용자로 간략 보기를 쓰고 있다면 간략 보기에서는 설정이 숨겨지므로, 먼저 팝업 위쪽의 전체를 누르세요.

    📝 파일명 형식에서 프롬프트 사용을 고르면 날짜, 시간, 프롬프트로 이름이 만들어집니다. 순서를 직접 정하고 싶다면 커스텀 템플릿을 고르고 이미지:와 동영상: 칸에 패턴을 입력하세요. Grok 기본은 프롬프트 없이 ID 기반의 짧은 이름을 유지합니다.

    설정은 바꾸는 즉시 자동으로 저장됩니다.

  3. 3

    단계 3: 메타데이터 저장으로 전체 프롬프트 남기기

    같은 영역에서 📋 메타데이터 저장("이미지/동영상 정보가 포함된 .json 파일도 저장 (프롬프트, 해상도 등)")을 켭니다. 이후 이미지와 동영상마다 같은 이름의 .json 파일이 옆에 생깁니다.

    파일명에서는 긴 프롬프트가 잘리기 때문에, 전체 프롬프트는 .json 파일에 남습니다. Grok 기본을 포함해 어떤 파일명 형식과도 함께 쓸 수 있습니다.

  4. 4

    단계 4: 소스를 고르고 목록 생성하기

    📥 다운로드 소스 및 필터에서 📦 모든 생성 미디어(대화별)(기본값, 전체 라이브러리), 🌟 즐겨찾기, 🏷️ 태그 중 하나를 고릅니다. 🎬 미디어 유형에서는 이미지를 체크된 상태로 두세요. 비디오 (Pro)는 PRO에서 체크할 수 있습니다.

    1. 목록 생성을 누릅니다. 설정에서 프롬프트를 쓰는 경우 버튼에 📝 프롬프트 가져오는 중과 진행 숫자가 나타나며, 확장 프로그램이 각 항목을 만든 대화에서 프롬프트를 찾아옵니다. 자체 프롬프트가 없는 동영상은 원본 이미지의 프롬프트를 이어받습니다. 한 번 찾은 프롬프트는 로컬 캐시에 남아 다음 실행이 더 빨리 끝납니다.

    스캔이 끝나면 📊 다운로드 요약 대화상자가 열려 다운로드할 이미지와 동영상 수, 화질별 동영상 수를 보여 주고 "다운로드를 시작하시겠습니까?"라고 묻습니다. 확인을 누르면 바로 다운로드가 시작됩니다. 취소를 누르면 대화상자가 닫히고 2. 다운로드 시작은 누를 수 있는 상태로 남으므로 먼저 설정을 확인할 수 있습니다. 아래 스크린샷이 그 상태입니다.

  5. 5

    단계 5: 다운로드 시작하기

    요약에서 취소를 눌렀다면 이제 2. 다운로드 시작을 누릅니다. 진행 막대에 진행 상황과 남은 예상 시간이 표시됩니다. ⏹ 다운로드 중지로 멈추고 ▶ 다운로드 계속으로 이어서 받을 수 있습니다.

    소스마다 다운로드 기록이 따로 저장되어, 다시 실행해도 이미 저장한 파일은 건너뜁니다. Grok의 제한을 넘지 않도록 확장 프로그램은 동영상 250개마다 잠시 멈췄다가(기본 3분, ⚙️ 설정에서 변경 가능) 스스로 다시 진행합니다.

  6. 6

    단계 6: 파일과 프롬프트 확인하기

    파일은 Chrome 다운로드 폴더 안의 grok_downloads/에 저장됩니다. 즐겨찾기는 images/와 videos/, 태그는 tags/ 아래 태그별 폴더, 전체 라이브러리는 conversations/ 아래 대화별 폴더에 저장됩니다. 대화 폴더 이름은 날짜, 제목이나 프롬프트, 짧은 ID로 만들어집니다. 경로는 ⚙️ 설정에서 바꿀 수 있습니다.

    메타데이터 저장을 켜 두면 각 미디어 파일 옆에 .json 파일이 함께 있습니다.

"프롬프트 사용" 파일명 예시

정확한 형식은 다운로드 소스에 따라 다릅니다. 아래 예시는 "a red fox in fresh snow"라는 프롬프트를 사용했습니다.

소스이미지동영상
📦 모든 생성 미디어img_20261128143015_a_red_fox_in_fresh_snow_1a2b3c4d.jpgvid_20261128143015_a_red_fox_in_fresh_snow_9e8d7c6b.mp4
🌟 즐겨찾기, 🏷️ 태그img_20261128143015_a_red_fox_in_fresh_snow.jpghd_20261128143015_a_red_fox_in_fresh_snow.mp4

14자리 숫자는 생성 날짜와 시간(YYYYMMDDHHmmss)이며, 컴퓨터의 시간대를 기준으로 합니다.

전체 라이브러리에서는 끝에 항목 ID의 마지막 8자가 붙습니다. 그래서 같은 프롬프트로 같은 초에 만든 두 항목도 이름이 겹치지 않습니다.

즐겨찾기와 태그의 동영상은 다운로드한 화질을 뜻하는 hd_ 또는 sd_로 시작합니다.

커스텀 템플릿 토큰

커스텀 템플릿을 고르고 이미지용과 동영상용 패턴을 각각 입력하세요. 확장 프로그램이 토큰을 바꾸고 확장자도 알아서 붙입니다.

토큰들어가는 값예시
{date}생성 날짜2026-11-28
{time}생성 시간(시, 분, 초)143015
{datetime}날짜와 시간2026-11-28_143015
{id}항목의 전체 Grok ID전체 ID
{shortid}ID의 마지막 8자1a2b3c4d
{prompt}파일명에 맞게 정리하고 80자로 자른 프롬프트a_red_fox_in_fresh_snow
{quality}즐겨찾기와 태그의 동영상은 hd 또는 sd, 이미지와 전체 라이브러리는 비어 있음hd

예시: 이미지 패턴을 {date}_{prompt}_{shortid}로 하면 2026-11-28_a_red_fox_in_fresh_snow_1a2b3c4d.jpg이(가) 됩니다.

알 수 없는 토큰은 지워집니다. 패턴에 {id}, {shortid}, {datetime} 중 아무것도 없으면 팝업에 "⚠ 고유 토큰 없음 — 파일이 덮어쓰일 수 있습니다"라는 경고가 표시됩니다. 이 중 하나를 넣으면 파일마다 고유한 이름이 붙습니다.

프롬프트가 없는 항목은 {prompt} 자리에 ID 일부가 들어갑니다. 템플릿 칸을 비워 두면 파일 이름은 ID가 됩니다.

.json 파일에 담기는 내용

📋 메타데이터 저장을 켜면 다운로드한 파일마다 같은 이름의 .json 파일이 생깁니다. 프롬프트는 기록된 그대로 저장되므로 파일명에 쓸 수 없는 문자도 남아 있습니다. 담기는 항목은 다음과 같습니다.

  • prompt, originalPrompt: 프롬프트 내용
  • createTime: 항목이 만들어진 시각, downloadedAt: 저장한 시각
  • id, type, url, filename: 어떤 항목이고 어디서 받았는지
  • userId: 내 Grok 계정 ID
  • 동영상에는 hdUrl, detailUrl, downloadedQuality(hd 또는 sd)가 추가됩니다

동영상의 경우를 줄여서 보여 주는 예시입니다.

{
  "id": "…",
  "type": "video",
  "url": "…",
  "filename": "vid_20261128143015_a_red_fox_in_fresh_snow_9e8d7c6b.mp4",
  "createTime": "2026-11-28T14:30:15.000Z",
  "prompt": "a red fox in fresh snow, slow camera pan",
  "originalPrompt": "a red fox in fresh snow, slow camera pan",
  "downloadedQuality": "hd",
  "downloadedAt": "2026-11-28T15:02:41.000Z"
}

파일에 Grok 사용자 ID가 들어 있으므로, 폴더를 공개적으로 공유할 때는 .json 파일을 빼는 것이 좋습니다.

프로젝트 폴더와 metadata.json (즐겨찾기 소스)

🌟 즐겨찾기 소스에서는 📂 다운로드 모드에서 프로젝트별을 고를 수 있습니다. 프로젝트 폴더마다 원본 이미지, 그 이미지로 만든 동영상, 그리고 metadata.json 하나가 들어갑니다. 폴더 이름은 날짜, 프롬프트, 짧은 ID로 만들어지며 예를 들면 20261128_a_red_fox_in_fresh_snow_1a2b3c4d입니다.

metadata.json에는 폴더의 프롬프트와 생성 시각, 원본 이미지, 생성된 각 동영상의 프롬프트와 다운로드 링크, 이미지와 동영상 개수가 기록됩니다. 메타데이터 저장 설정과 상관없이 모든 프로젝트 폴더에 기록됩니다. 표준 모드로 이미 받은 파일은 건너뛰므로, 완전한 프로젝트 폴더가 필요하면 팝업 안내대로 먼저 다운로드 기록을 지우세요.

프로젝트 폴더는 즐겨찾기 소스에서만 제공되고 동영상 중심이라 PRO와 함께 쓸 때 유용합니다. 또한 2026년 7월 Grok의 변경 이후 많은 계정에서 새로 생성한 미디어가 즐겨찾기에 들어가지 않습니다. 그런 항목은 📦 모든 생성 미디어를 쓰세요. 대화 폴더에는 이미지와 그 이미지로 만든 동영상이 처음부터 함께 들어갑니다.

파일명 길이와 문자 규칙

프롬프트는 파일 시스템을 고려해 쓴 글이 아니므로, 확장 프로그램이 파일명에 쓰기 전에 다음과 같이 정리합니다.

  • 파일명에 안전하지 않은 문자( \ / : * ? " < > | ), 줄바꿈, 탭은 지워집니다.
  • 공백은 밑줄로 바뀌고, 연속된 밑줄은 하나로 합쳐집니다.
  • 긴 프롬프트는 잘립니다. 전체 라이브러리의 "프롬프트 사용" 이름은 100자, 즐겨찾기와 태그는 120자, {prompt} 토큰은 80자, 프로젝트 폴더 이름은 90자까지입니다.
  • @와 ID로 쓴 이미지 참조나 프롬프트 끝의 --mode=… 같은 옵션은 이름에서 빠집니다. .json 파일에는 기록된 그대로의 프롬프트가 남습니다.
  • 한국어, 중국어, 일본어처럼 라틴 문자가 아닌 글자는 그대로 남습니다.
  • 직접 업로드한 이미지처럼 프롬프트가 없는 항목은 ID로 이름이 붙습니다.

이 규칙들은 .json 파일에는 적용되지 않습니다. 메타데이터 저장을 켜 두면 전체 프롬프트는 항상 남습니다.

팝업이 목록을 다시 생성하라고 할 때

프롬프트를 찾아오는 데는 시간이 걸리므로, 확장 프로그램은 설정에서 필요할 때만 가져옵니다. 프롬프트 사용 파일명, {prompt}가 들어간 커스텀 템플릿, 메타데이터 저장이 그 경우입니다.

Grok 기본 이름에 메타데이터 없이 목록을 만든 뒤 이 중 하나를 켜면, 팝업에 ⚠️ 프롬프트 파일명/메타데이터에는 프롬프트가 필요합니다. 목록을 다시 생성하세요라고 표시됩니다. 시작하기 전에 1. 목록 생성을 한 번 더 누르세요. 그러지 않으면 새 파일이 프롬프트 없이 저장됩니다.

문제 해결

프롬프트를 저장할 때 자주 겪는 문제와 해결 방법입니다.

파일명에 프롬프트 대신 ID가 들어갑니다
흔한 원인은 세 가지입니다. 업로드한 이미지처럼 항목에 프롬프트가 없는 경우입니다. 파일명 설정을 바꾸기 전에 목록을 만들었다면 다시 생성하세요. 예전 버전의 확장 프로그램으로 만든 목록이라면 확장 프로그램을 업데이트한 뒤 목록을 다시 생성하세요. Chrome은 확장 프로그램을 자동으로 업데이트하며, 바로 업데이트하려면 chrome://extensions에서 개발자 모드를 켜고 "업데이트"를 누르면 됩니다.
팝업에 "프롬프트 파일명/메타데이터에는 프롬프트가 필요합니다"가 표시됩니다
설정은 프롬프트를 쓰는데 지금 목록은 프롬프트 없이 만들어졌습니다. 1. 목록 생성을 다시 누른 다음 2. 다운로드 시작을 누르세요.
비디오 체크박스가 회색이고 자물쇠가 표시됩니다
동영상 다운로드는 PRO 기능입니다. 무료 버전에서도 모든 파일명과 메타데이터 옵션으로 이미지를 받을 수 있습니다. PRO는 $4.99 일회성 구매입니다(가격). 구매 후 GMD-… 키를 팝업의 🔑 라이선스에 붙여 넣으세요.
목록 생성이 "프롬프트 가져오는 중"에서 오래 걸립니다
처음 실행할 때는 목록에 있는 모든 대화의 프롬프트를 하나씩 찾아오므로, 라이브러리가 크면 시간이 걸립니다. Grok이 속도 제한을 걸면 확장 프로그램이 기다렸다가 다시 시도합니다. 다음 실행부터는 로컬 프롬프트 캐시를 써서 훨씬 빨라집니다. PRO라면 날짜 필터로 큰 스캔의 범위를 줄일 수도 있습니다.
두 파일의 이름이 같아졌습니다
커스텀 템플릿에 고유 토큰이 없습니다. {shortid}, {id}, {datetime} 중 하나를 넣으세요. 전체 라이브러리의 "프롬프트 사용" 이름은 이미 짧은 ID로 끝납니다.
형식을 바꿨는데 예전에 받은 파일은 이름이 그대로입니다
확장 프로그램은 이미 컴퓨터에 있는 파일의 이름을 바꾸지 않고, 다운로드 기록 때문에 그 파일들을 건너뜁니다. 새 이름으로 다시 받으려면 🧹 초기화를 열고 해당 소스의 기록을 지우세요. 전체 라이브러리는 "대화 기록 지우기", 즐겨찾기는 "다운로드 기록 초기화", 태그는 "태그 기록 삭제"입니다. 그런 다음 목록을 생성하고 다시 시작하세요. 기록을 지워도 Grok이나 컴퓨터의 파일은 전혀 삭제되지 않습니다.

그래도 해결되지 않나요? 자주 묻는 질문에서 더 많은 사례를 확인하거나 고객 지원 문의로 담당자에게 연락하세요.

자주 묻는 질문

Grok Imagine 동영상을 프롬프트와 함께 자동으로 다운로드할 수 있나요?

네. ⚙️ 설정에서 "프롬프트 사용"이나 {prompt}가 들어간 커스텀 템플릿을 고르고, 전체 프롬프트를 .json으로도 남기려면 📋 메타데이터 저장을 켜세요. 그 이후에 받는 모든 파일에 프롬프트가 남습니다. 동영상 다운로드에는 PRO가 필요하고, 이미지는 무료 버전에서 받을 수 있습니다.

프롬프트 저장은 무료인가요?

네. 파일명 형식, 커스텀 템플릿, .json 파일은 누구나 무료로 쓸 수 있습니다. $4.99 일회성 구매인 PRO는 동영상 다운로드, 최근 7일 이전의 라이브러리, 날짜 필터를 추가합니다. 자세한 내용은 가격 페이지에 있습니다.

파일명이 잘렸다면 전체 프롬프트는 어디에 있나요?

미디어 파일 옆의 .json 파일에 있습니다. 📋 메타데이터 저장을 켜면 만들어집니다. 파일명은 쓰기 편한 길이로 잘리지만 .json 파일에는 기록된 그대로의 프롬프트가 저장됩니다.

한국어나 일본어 같은 다른 언어의 프롬프트도 되나요?

네. 파일명에 안전하지 않은 문자만 지워지고, 한국어, 중국어, 일본어, 악센트가 있는 글자는 입력한 그대로 파일명에 남습니다.

이미지로 만든 동영상에는 어떤 프롬프트가 붙나요?

동영상에 자체 프롬프트가 있으면 그것을 씁니다. 자체 프롬프트가 없는 동영상은 원본 이미지의 프롬프트를 이어받으므로 이름이 여전히 의미 있게 붙습니다.

내 프롬프트가 어딘가로 업로드되나요?

아니요. 확장 프로그램은 브라우저 안에서 실행되며 파일은 Grok에서 내 컴퓨터로 바로 저장됩니다. 외부와 통신하는 곳은 PRO 키를 확인하는 Kario Studio의 라이선스 서버뿐입니다.
