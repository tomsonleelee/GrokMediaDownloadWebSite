Grok favorites not loading? Back up your library

Your Grok favorites look empty, stop at older items, or never show what you made this week? The cause is usually not your browser. Grok changed how it stores media in July 2026, and for many accounts the old Favorites list no longer receives new work. This guide explains what changed, what still works, and how to keep a complete copy of your Grok library on your own disk.

Short answer

Since Grok's July 2026 media backend change, newly generated images and videos are no longer added to the old Favorites list for many accounts. Anything that reads that list misses your recent work. The media itself is still in your Grok library.

To back it up, open grok.com/library, click the Grok Media Downloader icon, choose 📦 All Generated Media (by Conversation) as the Download Source, then click 1. Generate List and 2. Start Download. The free version saves images from the last 7 days. PRO adds videos, your full library and date filters.

What changed in July 2026

In July 2026 Grok moved its media to a new backend built around conversations and assets. Every image and video you generate now belongs to a conversation and is stored as an asset in your library. Since that change, the older Favorites list, which Grok's pages show as Saved, stopped receiving newly generated media for many accounts.

The effect is easy to misread. The list may still show items from earlier, so it does not look broken. It simply misses what you generated more recently. Any tool that relies on that list has the same gap, including older versions of browser extensions and the 🌟 Favorite source in Grok Media Downloader.

Grok Media Downloader adapted to the new backend in version 2.5.0. Since version 2.5.1 the 📦 All Generated Media (by Conversation) source, which reads your whole library instead of the Favorites list, is the default and free for everyone. Under the Favorite source the popup now shows a reminder: “⚠️ Since Grok's July 2026 change, newly generated media is no longer added to Favorites — the latest items may be missing here.”

Grok's own page does not load at all?

A blank page, an error message or an endless spinner on grok.com is a problem on Grok's side or with your connection, and no extension can fix it. Check Grok's own help, or try again later. The steps below are about getting your media out once grok.com loads normally.

What still works

  • Your library. Media generated after the change is still stored in your Grok library. The 📦 All Generated Media source reads that library directly, so it finds the recent work a Favorites scan misses, grouped by the conversation it came from.
  • Your older favorites. The 🌟 Favorite source still downloads whatever the old list contains. Use it when you want exactly that curated set and nothing else.
  • Tags. If you organize work into Grok tags, the 🏷️ Tag source downloads everything in one tag.
  • Download history. Each source keeps its own record of what you already saved, so running the same backup again only fetches new files.

In short, the Favorites list has become an incomplete view of your work, while the library is still complete. A backup that reads the library does not depend on that list at all.

November 2026: Imagine moved into Grok's Library

A second change followed on 12–13 November 2026. Grok folded Imagine into the main Grok app, and the sidebar now shows Library. On some accounts the Imagine tab and the /imagine pages disappeared, and those addresses now redirect to Library or to the home page. If you used to open your favorites through the Imagine tab, look for Library in the sidebar, or go straight to grok.com/library.

Extension versions before 2.6.3 only enabled their buttons on /imagine pages, so after this change 1. Generate List and 2. Start Download could stay greyed out. Version 2.6.3 works on any grok.com page, and grok.com/library is the recommended place to use it. If your buttons are greyed out, follow Grok download button missing after update first, then come back here.

How to back up your whole Grok library

The steps below use the 📦 All Generated Media (by Conversation) source. It reads your library rather than the Favorites list, puts files into one folder per conversation, and skips anything you already downloaded. A first run on a large library can take a while, so start it when you can leave the tab open.

  1. 1

    Install or update Grok Media Downloader

    Add Grok Media Downloader from the Chrome Web Store and pin it to the toolbar so the icon stays visible. If you already have it, check that the version is 2.6.3 or newer: open chrome://extensions and read the version number on the extension's card.

  2. 2

    Open grok.com and sign in

    Open grok.com/library and make sure you are signed in to the account you want to back up. Any grok.com page works since version 2.6.3, and grok.com/imagine/saved works too on accounts that still have it. Keep this tab active when you click the extension icon.

  3. 3

    Choose 📦 All Generated Media as the Download Source

    Click the extension icon to open the popup. In the 📥 Download Source & Filter section, under 🎯 Download Source, select 📦 All Generated Media (by Conversation). It is the default on current versions, but check it if you switched sources before. On the free version a note appears below it: “ℹ️ Free version scans the last 7 days only. Upgrade to Pro for your full library and date filters.”

  4. 4

    Pick media types and, with PRO, a date range

    Under 🎬 Media Types, keep 🖼️ Images checked. 🎬 Videos (Pro) is locked on the free version. With PRO you can also limit a run to a Date Range or to the last few hours, or leave the filter on Download All to archive everything. Free runs always cover the last 7 days.

  5. 5

    Click 1. Generate List

    The extension scans your library, newest first, and counts what it finds. While it works, the popup shows how many items it has found so far. When it finishes, a 📊 Download Summary dialog lists how many images and videos still need downloading, with videos broken down into 1080p, HD, 720p and SD, and asks “Start download?”. Click OK to start right away. Click Cancel if you want to look at the list first: the counts stay in the popup and 2. Start Download stays enabled.

    If the scan is cut short, the popup says “Scan interrupted — partial list saved”. Wait a few minutes and click 1. Generate List again.

  6. 6

    Start the download

    If you clicked OK in the summary, the download is already running; otherwise click 2. Start Download. Files download one after another. A progress bar with an estimate of the time left shows how far the run is, and ⏹ Stop Download stops it. Keep the grok.com tab open until the run finishes. To continue later, click 2. Start Download again; files that are already saved are skipped. Runs with more than 250 videos include planned pauses: after every 250 videos the extension waits, three minutes by default, and then continues by itself. The Download Summary warns you about this before the run starts, and you can set the pause to anything from 1 to 60 minutes under ⏱️ Rate Limit Cooldown in ⚙️ Settings.

  7. 7

    Find your files

    Files go to Chrome's download folder. The whole-library source saves them under grok_downloads/conversations, with one folder per conversation, so an image and the videos made from it stay together. You can change the folder names in ⚙️ Settings.

  8. 8

    Repeat the backup from time to time

    Click 1. Generate List and 2. Start Download again whenever you want to bring the backup up to date. Only new files are downloaded. On the free version, running it once a week keeps up with the 7-day window for images.

Troubleshooting

Most problems after Grok's 2026 changes come down to the selected source, the free 7-day window or the active tab. Start with these.

Generate List finds nothing

Check three things. First, the Download Source: if it says 🌟 Favorite, switch to 📦 All Generated Media (by Conversation). Second, the time window: the free version only looks at the last 7 days, so the list is empty if you generated nothing in that time. Third, the download history: the list only counts files that still need downloading, so after a complete run there may be nothing left to do.

My newest images are missing from the list

The list is a snapshot taken when you click 1. Generate List. Make sure the source is 📦 All Generated Media, not 🌟 Favorite, and generate the list again to include anything made since the last scan.

Generate List and Start Download are greyed out

Either the active tab is not a grok.com page, or your extension is older than 2.6.3 and does not work on grok.com/library. See Grok download button missing after update.

Videos are not downloaded

The free version downloads images only, so 🎬 Videos (Pro) is locked. With PRO, check the box and click 1. Generate List again before you start.

Downloads start failing after a long run

On very long runs Grok can start refusing downloads, for example with HTTP 403 errors after thousands of videos. Reload the grok.com tab, open the popup and click 2. Start Download again. Files that are already saved are skipped.

The popup says “Generation Failed”

Make sure you are signed in on grok.com, reload the tab and try again.

I deleted the files and the extension says everything is already downloaded

Each source keeps its own download history. For the whole-library source, open 🧹 Clear Actions and click Clear Conversation History. This only resets the extension's record; nothing is deleted on Grok or on your disk.

Frequently asked questions

Is my Grok media gone if it is not in Favorites?

Usually not. Since July 2026, newly generated media is no longer added to the old Favorites list for many accounts, but it is still stored in your Grok library. The 📦 All Generated Media source reads the library, which is why it finds recent work that a Favorites scan misses. If something is missing from Grok's Library as well, check Grok's own help.

Can I back up my Grok library for free?

Yes, within limits. The free version downloads images from the last 7 days with the 📦 All Generated Media source. PRO, a one-time $4.99 purchase, adds videos, your full library with no time limit, and date filters. See the pricing page.

Where are the downloaded files saved?

In Chrome's download folder. The whole-library source uses grok_downloads/conversations, with one folder per conversation. The Favorite source uses grok_downloads/images and grok_downloads/videos, and the Tag source uses grok_downloads/tags. You can change these paths in ⚙️ Settings.

Will running the backup again download duplicates?

Not within the same source. Each source keeps a download history, and files you already saved are skipped, so the next run only downloads new media. The histories are separate, though: a file you saved through 🌟 Favorite can be downloaded again by 📦 All Generated Media.

Should I still use the Favorite source?

Use it if you want exactly the set the old Favorites list contains. For anything generated since July 2026, or for a complete backup, use 📦 All Generated Media (by Conversation).

Does the extension upload my media anywhere?

No. Everything runs locally in your browser, and files go straight from Grok to your disk. The only outside connection is the PRO license check, which talks to Kario Studio's license server.
